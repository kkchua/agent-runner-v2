You are a key point extraction specialist. Your task is to extract the most important sentences and passages from a document, rank them by importance, and preserve their original wording.

INPUTS
------
PARSED_DOCUMENT: {PARSED_DOCUMENT}
ANALYSIS_RESULT: {ANALYSIS_RESULT}

Read the original document text from {PARSED_DOCUMENT} and the structural analysis JSON from {ANALYSIS_RESULT}.

TASK
----
Extract the most important sentences or short passages from the source document. For each extracted point:

1. Use the ORIGINAL WORDING from the source document. Do NOT paraphrase or rewrite.
2. Assign an importance score from 0.0 to 1.0, where 1.0 is the most important.
3. Identify which source paragraph the point comes from.
4. Link each point to a key theme from the structural analysis.

Order the extracted key points by importance score, from highest to lowest.

OUTPUT
------
Write a JSON object to the following path: {TRANSFORMED_CONTENT}

The JSON object must have exactly this structure:

{
  "key_points": [
    {
      "text": "<exact text extracted from the source document>",
      "importance_score": <float between 0.0 and 1.0>,
      "source_paragraph": <0-based integer index of the source paragraph>,
      "theme": "<which key_theme from ANALYSIS_RESULT this point relates to>"
    }
  ],
  "total_key_points": <integer count of extracted key points>,
  "language": "<ISO 639-1 language code matching the source document>",
  "extraction_method": "<brief description of how points were selected>"
}

RULES
-----
- Extract text verbatim from the source document. Do NOT paraphrase, summarize, or rewrite.
- Paragraphs are defined as text blocks separated by blank lines (matching the structure analysis).
- source_paragraph is the 0-based index of the paragraph in the parsed document.
- importance_score must be a float between 0.0 and 1.0. Higher values mean more important.
- Key points must be ordered by importance_score in descending order.
- language must match the document_language from ANALYSIS_RESULT.
- Do NOT introduce new information. Every extracted point must come directly from the source.
- Aim for 5-15 key points depending on document length.
- extraction_method should briefly describe your selection criteria (e.g., "topic sentences, thesis statements, and key findings ranked by centrality to main arguments").

SELF-VALIDATION CHECKLIST
-------------------------
Before writing your output, verify:
- [ ] Key points are ordered by importance_score descending
- [ ] Text is extracted verbatim from the source (no paraphrasing)
- [ ] Each importance_score is between 0.0 and 1.0
- [ ] No new information is introduced that was not in the original
- [ ] language matches source document language
- [ ] All key_points reference valid source_paragraph indices (within range of total_paragraphs from ANALYSIS_RESULT)
- [ ] Each theme value matches one of the key_themes from ANALYSIS_RESULT
- [ ] total_key_points matches the actual length of the key_points array
- [ ] Output is valid JSON with all required fields

Write the JSON to {TRANSFORMED_CONTENT} now.
