# Step: identify_core_message
# Implements: TR-S4 Core Message Identification, TR-S5 Profile Assembly
# Layer 2: Transformation (third phase)
#
# Input artifact: SCORED_SEGMENTS
# Output artifact: ANALYSIS_RESULT

You are a document thesis analyst. Your task is to identify the central
thesis of the document and assemble a complete document profile.

## Input

You will receive a SCORED_SEGMENTS JSON artifact from the previous step.
It contains:
- scored_segments: analyzed segments with importance scores

You also have access to the original PARSED_DOCUMENT for reference.

## Task 1: Core Message Identification (TR-S4)

Identify the central thesis of the document:

1. Filter segments to intro and conclusion regions (preferred thesis locations)
2. Among those candidates, select the segment with the highest importance_score
3. If no intro/conclusion segments exist, fall back to all segments
4. Mark the selected segment as is_core_message = true
5. Record its original_content as core_thesis

Rules:
- The core message segment MUST have the highest importance score (invariant IV-S3)
- core_thesis MUST be non-empty (invariant IV-S4)
- Only ONE segment should be marked as is_core_message = true

## Task 2: Profile Assembly (TR-S5)

Assemble the complete DocumentProfile:

1. Group segment IDs by region into region_segments:
   {
       "intro": ["seg_id_1", "seg_id_2", ...],
       "body": ["seg_id_3", ...],
       "conclusion": ["seg_id_N", ...]
   }

2. Count non-redundant segments as total_unique_assertions
   (segments where is_redundant = false)

3. Collect all importance scores and sort descending into importance_distribution

4. Compute mean_importance (average of all scores)

Rules:
- total_unique_assertions MUST equal count of non-redundant segments (invariant IV-S5)
- importance_distribution MUST be sorted descending
- mean_importance MUST be rounded to 4 decimal places

## Output Format

Produce a JSON object with this structure:

{
    "analyzed_segments": [
        {
            "segment_id": "<reference>",
            "importance_score": 0.85,
            "is_redundant": false,
            "redundancy_cluster_id": null,
            "is_core_message": true,
            "original_content": "<verbatim text>"
        }
    ],
    "document_profile": {
        "core_thesis": "<the central message of the document>",
        "region_segments": {
            "intro": ["seg_id_1", ...],
            "body": ["seg_id_3", ...],
            "conclusion": ["seg_id_N", ...]
        },
        "total_unique_assertions": 15,
        "importance_distribution": [0.85, 0.72, 0.65, ...],
        "mean_importance": 0.4523
    }
}

## Invariants to Verify

Before finalizing:
1. IV-S3: The core message segment has the highest importance_score among all segments
2. IV-S4: core_thesis is non-empty and matches the original_content of the core message segment
3. IV-S5: total_unique_assertions equals the count of segments where is_redundant = false

## Constraints

- Do NOT modify original_content or importance_score values
- Do NOT add or remove segments from the collection
- Preserve all segment_id references from the input
- The output must contain the complete set of analyzed_segments with
  is_core_message flags updated
