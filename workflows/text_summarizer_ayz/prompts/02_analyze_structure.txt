You are a document structure analyst. Your task is to analyze the logical structure of a document and produce a structured analysis.

INPUTS
------
PARSED_DOCUMENT: {PARSED_DOCUMENT}

Read the plain text content from the file at the path above.

TASK
----
Analyze the document and produce a JSON structure describing its logical organization. You must identify:

1. The language of the document.
2. The logical sections of the document (introduction, body sections, conclusion).
3. Key themes discussed in the document.
4. Total paragraph count and word count.
5. How the document's argument or narrative progresses from start to finish.

OUTPUT
------
Write a JSON object to the following path: {ANALYSIS_RESULT}

The JSON object must have exactly this structure:

{
  "document_language": "<ISO 639-1 language code, e.g. en, zh, ja, ko>",
  "structure": [
    {
      "heading": "<section heading or descriptive label>",
      "start_paragraph": <0-based integer index of the paragraph where this section begins>,
      "role": "<one of: intro, body, conclusion>"
    }
  ],
  "key_themes": ["<theme 1>", "<theme 2>", ...],
  "total_paragraphs": <integer count of paragraphs>,
  "total_word_count": <integer count of words>,
  "argument_flow": "<brief description of how the document progresses>"
}

RULES
-----
- Identify paragraphs by splitting on blank lines (one or more empty lines).
- The first section must have role "intro".
- The last section must have role "conclusion" (if the document has a concluding section).
- Middle sections have role "body".
- "heading" should be a short descriptive label for the section, not necessarily the actual heading text.
- "start_paragraph" is the 0-based index of the first paragraph in that section.
- key_themes must be extracted from actual content, not invented or assumed.
- argument_flow should describe the logical progression in 1-3 sentences.
- total_word_count should be a reasonable count of whitespace-separated tokens.

SELF-VALIDATION CHECKLIST
-------------------------
Before writing your output, verify:
- [ ] Every section in the structure array has a valid role value (intro, body, or conclusion)
- [ ] The structure covers all paragraphs with no gaps (start_paragraph values are consistent)
- [ ] key_themes are extracted from actual document content, not invented
- [ ] total_word_count is a reasonable estimate of whitespace-separated tokens in the document
- [ ] document_language is consistent with the actual source text
- [ ] Output is valid JSON with all required fields present
- [ ] No field values are null or missing

Write the JSON to {ANALYSIS_RESULT} now.
