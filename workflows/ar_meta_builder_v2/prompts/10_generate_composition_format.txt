# Objective

Produce the Composition Format (Layer 2) for the target workflow.
Define how domain components bind together, override mechanisms,
placeholder resolution, and ordering constraints.

# Reference Inputs

- WORKFLOW_SPEC_FILE: {WORKFLOW_SPEC_FILE}
- TEST_CRITERIA_FILE: {TEST_CRITERIA_FILE}
- DOMAIN_ANALYSIS_FILE: {DOMAIN_ANALYSIS_FILE}
- DOMAIN_COMPONENT_SCHEMA_FILE: {DOMAIN_COMPONENT_SCHEMA_FILE}

# Generation Tasks

1. **Composition Structure** -- YAML template showing all component
   bindings with component_id and overrides.

2. **Binding Rules** -- One per component type. Each rule specifies:
   source phase, consumed by phases, required flag, pattern name.

3. **Override Mechanism** -- Shallow merge strategy. Define
   non-overridable properties (all 7 common properties). Define
   override rules for identity fields and base schema path.

4. **Placeholder Resolution** -- Define all 7 placeholders:
   WORKFLOW_SPEC_FILE, BASE_COMPOSITION_STANDARD, standard_name,
   standard_version, standard_filename, output_type, workflow_name.
   Specify resolution order and unresolved handling.

5. **Ordering Rules** -- Constraints on binding order (foundation
   first, layer sequence, terminal last).

6. **Meta-Test-Criteria Binding** -- How Phase 1 meta-test-criteria
   propagate to all subsequent gatekeep prompts.

7. **Self-Validation** -- Verify all types have bindings, all
   placeholders defined.
