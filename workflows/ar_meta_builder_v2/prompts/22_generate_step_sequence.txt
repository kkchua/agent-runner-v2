# Generation Tasks

1. **Step Definitions** -- Table with: step name, type (prompt/action),
   routing (onsuccess), role policy.

2. **Review/Refine Loops** -- For each generate step, define the
   review and refine pair with on_reject_refine configuration.

3. **Approval Gates** -- If output_type = documented_versioned,
   define where human approval is required.

4. **Delivery Mechanism** -- How output is delivered:
   - documented_versioned: review -> approve -> promote -> archive
   - direct: generate -> promote

5. **Artifact Flow Chains** -- Trace each artifact from producer
   to consumer. Verify no temporal violations.

6. **Self-Validation** -- Verify routing valid, no dangling refs.
