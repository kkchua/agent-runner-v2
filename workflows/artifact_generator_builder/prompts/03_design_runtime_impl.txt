2. **Input Loading** -- How to load and parse input:
   - File reading and parsing logic
   - Validation of input format
   - Conversion to meta content structure

3. **Transformation Engine** -- Core processing logic:
   - Step-by-step transformation process
   - How composition spec rules are applied

4. **Output Generation** -- How to produce output:
   - Rendering/assembly logic
   - File writing and formatting
   - Validation of output format

5. **Configuration** -- Runtime parameters:
   - What can be configured at runtime?
   - Default values and overrides
   - Environment-specific settings

6. **Extension Interface** -- How to add new implementations:
   - What interfaces must new implementations follow?
   - What hooks/extension points exist?
   - How to register new implementations?

7. **Self-Validation** -- Verify implementation follows composition spec
