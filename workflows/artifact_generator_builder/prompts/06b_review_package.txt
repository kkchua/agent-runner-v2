# Review Protocol

Follow these steps IN ORDER.

## Step 1: Mental Execution

Execute the workflow mentally as the daemon would:
1. Parse workflow.toml — does it load without errors?
2. Start at init_step — follow the routing chain to completion
3. For each step — resolve its prompt file path, verify all `{placeholder}` keys are provided by context_extensions.py
4. For each action step — verify the action name matches a function in actions.py
5. Check artifact flow — every step's required_inputs are produced by prior steps

Note every point where the mental execution fails.

## Step 2: Cross-File Consistency

Check for broken references between files:
- Artifact keys in workflow.toml match context_extensions.py registrations
- Prompt placeholders reference keys that exist
- Action names match registered functions
- [[workflow.implementation]] declarations match impls/ directories (if present)

## Step 3: Verdict

- **PASS** — The package is executable. Minor observations may be noted but do not block promotion.
- **REJECT** — The package has blocking defects (broken references, missing files, routing errors) that will cause runtime failures. State what must be fixed.

# Output Instructions

Write to: {REVIEW_PACKAGE_FILE}

# Forbidden Content
