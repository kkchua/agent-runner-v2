# Attack Protocol

## Step 1: Trace Every Claim

For EVERY claim in the composition spec, ask: "What happens when..."

- "The spec says it handles .pdf files. What happens when the PDF is scanned (image-only, no text layer)? Does the design account for this?"
- "The spec says it preserves the source language. What happens when the input is mixed-language? What detection mechanism? What if detection fails?"
- "The spec says importance scoring uses 4 factors. What are the exact weights? What happens when all factors produce equal scores? What is the tie-breaking rule?"
- "The spec says redundancy detection uses pairwise comparison. What happens with 500 sentences? Is O(n^2) acceptable? What is the similarity threshold? What happens at the threshold boundary?"

## Step 2: Attack the Data Flow

Trace data from input to output. At each stage, ask:

- What data is LOST at this stage? Is the loss acceptable?
- What data is TRANSFORMED? Can the transformation be reversed? Should it be?
- What data is ADDED? Is the addition justified by the source?
- Are there stages where the output is underspecified? Could two different implementations produce incompatible outputs?

## Step 3: Attack the Extension Points

For each extension point:

- Can an extension BREAK the invariants? What prevents a custom InputParser from returning garbage?
- Are the Protocol definitions tight enough? Can an implementer misinterpret the contract?
- What happens when an extension throws an error? Is error handling specified?

## Step 4: Attack the Variants

For each implementation variant:

- Does the override pattern actually work? Are there steps that SHOULD be overridden but aren't?
- Can the variant produce output that violates the composition spec's invariants?
- Are the variant's differences from the default fully enumerated? Or are there implicit assumptions?

## Step 5: Attack the Constraints

For each constraint:

- Is it MEASURABLE? Can you write a test that verifies it?
- Is it ENFORCEABLE? What mechanism prevents violation?
- What happens when constraints CONFLICT? (e.g., "preserve all key points" vs "max 20% word count")
