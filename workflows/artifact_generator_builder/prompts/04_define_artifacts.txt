# Objective

Define the artifact contract for the generated workflow. Specify all artifact keys, their types, paths, and relationships.

- REQUIREMENT_ANALYSIS_FILE: {REQUIREMENT_ANALYSIS_FILE}

# Generation Tasks

Produce an artifact contract containing:

1. **Input Artifacts** -- What the generated workflow accepts:
   - Artifact keys and descriptions
   - Expected file types/formats
   - Path patterns

2. **Output Artifacts** -- What the generated workflow produces:
   - Artifact keys and descriptions
   - Output file types/formats
   - Path patterns

3. **Intermediate Artifacts** -- Internal processing artifacts:
   - Meta content files
   - Temporary processing files
   - Validation reports

4. **Artifact Relationships** -- Dependencies and flow:
   - Which artifacts depend on which
   - Processing order constraints
   - Optional vs required artifacts

5. **Naming Conventions** -- Patterns for artifact paths:
   - Use {job_id} for run-specific paths
   - Use {seq} for sequence numbers
   - Consistent naming patterns

6. **Self-Validation** -- Verify all artifacts from requirement are covered

# Self-Critic

- Are all input artifacts from the requirement listed?
- Are all output artifacts from the requirement listed?
- Are path patterns consistent?
- Are relationships clear?

# Forbidden Content

- Do NOT use absolute paths
- Do NOT hardcode job IDs or sequence numbers
- Do NOT include non-ASCII characters
