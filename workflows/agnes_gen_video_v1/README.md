# Agnes Video Generation v1

Generate videos from images using the Agnes Video V2.0 API. This workflow extracts prompts from PNG metadata (ComfyUI-generated images) and calls the video generation API.

## Overview

This workflow scans `step_03_generatedimage/` for PNG images, extracts `t2i_prompt1` and `t2i_prompt2` from the embedded ComfyUI workflow metadata, and uses `t2i_prompt1` to generate videos via the Agnes Video API.

## Workflow Steps

1. **generate_videos** — Scans `step_03_generatedimage/` for PNG files, extracts prompts from metadata, calls video generation API, downloads videos to `step_04_generatedvideo/`
2. **archive_step_03** — Archives processed inputs from `step_03_generatedimage/` to `step_03_generatedimage_archive/` (only files listed in `step_04_generatedvideo/index.json`)
3. **stepCompletion** — Terminal step

## Directory Structure

```
<project_root>/
├── step_03_generatedimage/        # Input PNG images (with embedded ComfyUI metadata)
├── step_04_generatedvideo/        # Output videos (.mp4) + index.json
├── step_03_generatedimage_archive/ # Archived processed inputs
├── step_04_generatedvideo_archive/ # Archived processed outputs (if needed)
├── config.json                    # Media configuration (model, dimensions, timeouts)
```

## PNG Metadata Extraction

The workflow extracts prompts from PNG files generated by ComfyUI. The metadata is stored in `tEXt` chunks with keyword `prompt`, containing the full workflow JSON.

**Extracted fields:**
- `t2i_prompt1` — Text-to-image prompt (scene description)
- `t2i_prompt2` — Secondary prompt (camera/motion description)

The workflow uses `t2i_prompt1` as the video generation prompt.

## Configuration

### config.json

```json
{
  "video": {
    "model": "agnes-video-v2.0",
    "width": 1024,
    "height": 576,
    "num_frames": 72,
    "frame_rate": 24
  },
  "max_concurrent": 2,
  "process_delay": 15,
  "api_timeout": 500,
  "api_max_retries": 5,
  "retry_base_wait": 5
}
```

### .env

```bash
# API key(s) for round-robin rotation
AGNES_API_KEY_1=your_api_key_here
AGNES_API_KEY_2=your_second_api_key_here

# Optional: custom API base URL
# AGNES_BASE_URL=https://apihub.agnes-ai.com
```

## API Key Rotation

The workflow supports multiple API keys for round-robin rotation. Define numbered keys (`AGNES_API_KEY_1`, `AGNES_API_KEY_2`, ...) in `.env`. The workflow automatically rotates through them for each API call.

## Usage

1. Place PNG images (with ComfyUI metadata) in `step_03_generatedimage/`
2. Create `config.json` with video generation settings
3. Configure `.env` with API key(s)
4. Run the workflow via operator console or CLI

## Output

- `step_04_generatedvideo/*.mp4` — Generated videos (named after input PNGs)
- `step_04_generatedvideo/index.json` — Manifest listing input-to-output mappings

## Error Handling

- **Partial failure**: If some videos fail, successfully processed files are saved and the workflow returns REJECTED with error details
- **Retry logic**: HTTP 503/429 errors trigger exponential backoff retry
- **Missing metadata**: PNG files without `t2i_prompt1` are skipped with a warning
