Objective

Scan the directory referenced by {STEP_01_DIR} for description JSON
files produced by the extract_descriptions step. For each description
JSON, generate N variant prompt sets (where N is read from the
num_variants field in {MEDIA_CONFIG}, defaulting to 4 if not
specified). Each variant must include a t2i_prompt1 field containing
a detailed English text-to-image prompt derived from the description
data, and a t2v_prompt1 field containing a detailed English
text-to-video prompt optimized for image-to-video animation. Save
variant JSONs to {STEP_02_DIR} with filenames matching the input
description stems. After processing all descriptions, archive the
processed description JSONs by copying them to {STEP_01_ARCHIVE}
and removing them from {STEP_01_DIR}. Finally, produce an index.json
file in {STEP_02_DIR} listing all input-to-output file mappings.

Reference Inputs

- Description JSONs directory: {STEP_01_DIR}
- Output variants directory: {STEP_02_DIR}
- Archive directory for processed descriptions: {STEP_01_ARCHIVE}
- Media configuration: {MEDIA_CONFIG}
- Governance docs: {GOVERNANCE_RUNTIME_ROOT}
- Platform docs: {PLATFORM_RUNTIME_ROOT}

Output Instructions

For each description JSON file found in {STEP_01_DIR}, read the
descriptions array and generate variant prompt sets. The number of
variants per description is determined by the num_variants field
in {MEDIA_CONFIG} (default 4).

Each variant must contain:
- t2i_prompt1: A detailed, descriptive English text-to-image prompt.
  The prompt should incorporate the subject attributes, scene
  attributes, composition, lighting, style, color palette, and mood
  from the description data. Prompts must be in English. Prompts
  should be rich enough to guide an image generation model to produce
  visually similar results to the source image.

  CRITICAL STYLE REQUIREMENT: All prompts MUST be photorealistic
  photography style. These images will be used for video generation,
  so they must look like real photographs, NOT paintings or artwork.

  FORBIDDEN STYLES (do NOT use these):
  - painting, oil painting, watercolor, acrylic, gouache
  - illustration, digital art, concept art, anime, cartoon
  - sketch, drawing, charcoal, pencil art
  - abstract, surreal, fantasy art, sci-fi art
  - Any non-photographic artistic rendering

  REQUIRED STYLE: Photorealistic photography — must look like a real
  photo taken with a camera. Use photography terminology and styles.

  CRITICAL VARIANCE REQUIREMENT: Each variant MUST be visually distinct
  from the others. Vary these PHOTOGRAPHY dimensions across variants:
  • Photography style: portrait, landscape, macro, street, documentary,
    fashion, architectural, product photography, etc.
  • Lighting: golden hour, dramatic chiaroscuro, soft diffused, neon,
    backlight, rim light, studio lighting, natural light, etc.
  • Color palette: warm tones, cool tones, monochrome, vibrant saturated,
    muted pastel, high contrast, etc.
  • Composition: close-up macro, wide establishing shot, bird's eye view,
    low angle, dutch angle, rule of thirds, centered, etc.
  • Mood/atmosphere: ethereal, gritty, serene, dynamic, mysterious,
    nostalgic, futuristic, etc.
  • Time/season: dawn, midday, dusk, night; spring, summer, autumn, winter
  • Camera technique: shallow depth of field (bokeh), tilt-shift, motion
    blur, long exposure, HDR, specific lens (50mm, 85mm, 24mm wide), etc.

  
- t2v_prompt1: A detailed English text-to-video prompt optimized for
  image-to-video animation. This prompt should describe the motion,
  camera movement, and dynamic elements of the scene. Focus on how
  elements move rather than static appearance. Include camera motion
  (pan, zoom, tilt, dolly), subject motion (walking, flowing,
  rotating), and atmospheric dynamics (wind, particles, lighting
  changes). Keep the prompt concise and motion-focused.
- negative_prompt_video: A negative prompt for video generation describing
  what to AVOID in the output video. Include unwanted motion artifacts
  (jitter, flicker, warping, morphing), unwanted camera movements (shaky
  cam, erratic zoom), unwanted visual elements (blurry, low quality,
  distorted faces, extra limbs), and style mismatches. Keep it concise
  and focused on video-specific artifacts.
  
  VARIANCE REQUIREMENT: Each variant's video prompt should match the
  visual style of its corresponding t2i_prompt1 and describe motion
  appropriate to that style (e.g., gentle camera drift for serene mood,
  dynamic tracking shot for action mood).

    }

Each variant within the variations array must have:
- t2i_prompt1: A detailed English text prompt for image generation.
  CRITICAL: Each variant MUST be visually distinct — vary photography
  style, lighting, color palette, composition, mood, time/season, and
  camera technique across variants. Do NOT generate similar prompts
  with minor word changes. Each variant should look like it was taken
  by a different photographer with a unique vision. ALL variants must
  be photorealistic — NO painting, illustration, or artistic styles.
- t2v_prompt1: A detailed English text prompt for video generation.
  Each variant should describe motion and camera dynamics that match the
  visual style of its corresponding t2i_prompt1. Focus on movement, not
  static appearance.
- negative_prompt_video: A negative prompt describing what to avoid
  in the video output (motion artifacts, unwanted elements, style
  mismatches). This will be combined with negative_prompt_video_postfix
  from config.json before sending to the API.
- image_filename: Output image filename following the pattern
  {stem}_NN.png where NN is two-digit zero-padded (01, 02, 03, etc.).
- image_url: Empty string (this field will be populated by the
  generate_images step).

After writing all variant JSONs to {STEP_02_DIR}:

1. Copy each processed description JSON file from {STEP_01_DIR} to
   {STEP_01_ARCHIVE}.
2. Remove each processed description JSON file from {STEP_01_DIR}.
3. Write an index.json file to {STEP_02_DIR} with this structure:
   {
     "step": "generate_prompts",
     "files": [
       {"input": "step_01/image001.json", "output": "step_02/image001.json"}
     ]
   }

PRE-WRITE SELF-CHECK (mandatory before writing each variant JSON):
Before writing each variant JSON file, verify:
-ALL prompts are photorealistic photography style (NO painting, illustration, or artistic styles)
- No forbidden styles appear (painting, watercolor, anime, cartoon, sketch, etc.)
- Photography style varies across variants (portrait, landscape, macro, etc.)
- Lighting conditions vary across variants (e.g., golden hour vs. dramatic vs. soft)
- Color palettes differ (e.g., warm vs. cool vs. monochrome)
- Composition angles vary (e.g., close-up vs. wide shot vs. aerial)
- Mood/atmosphere is different for each variant
- Each t2v_prompt1 matches the visual style of its corresponding t2i_prompt1

All output must be ASCII-only JSON with UTF-8 encoding.

CRITICAL: Output Mechanism

You MUST use your file-writing tools to create actual files on disk. Do NOT
put artifact data in the meta.json result field -- the result field is for
status and summary information ONLY.

Required file outputs:
1. Individual variant JSONs: {STEP_02_DIR}/<image_stem>.json for each
   input description (e.g., step_01/image001.json -> step_02/image001.json)
2. Index file: {STEP_02_DIR}/index.json listing all input-to-output mappings
   (this is the {PROMPT_VARIANTS} artifact)

Your meta.json result field should contain only:
- status: "complete" or "error"
- remark: brief summary (e.g., "Generated 4 variants each for 5 descriptions, wrote 5 JSONs + index")
- Do NOT include the full JSON data in the result field

In the artifacts field of meta.json, you MUST report:
- PROMPT_VARIANTS: the absolute path to the index.json file you wrote
  (e.g., "D:/path/to/repo/step_02/index.json")

Artifacts

The {PROMPT_VARIANTS} artifact is the index.json file you write to
{STEP_02_DIR}/index.json. This file must exist on disk after step completion.
You must report this absolute path in the artifacts field of meta.json.
