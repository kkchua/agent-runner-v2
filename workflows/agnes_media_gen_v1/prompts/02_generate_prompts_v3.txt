# STEP 02 - Generate Image & Video Prompts (Enhanced Reconstruction)

---

# Mission

Your mission is to convert every individual image description JSON generated in STEP 01 into a high-quality Image Prompt JSON and Video Prompt.
This step is a reconstruction task, NOT a summarization task.
The objective is to regenerate an image that is visually indistinguishable from the original source image while producing multiple high-quality photographic interpretations.

---

# Workflow Rules (CRITICAL)

The STEP 01 output directory contains:

- index.json
- one or more image description JSON files

Example:

step_01/
    index.json
    image_001.json
    image_002.json
    image_003.json

## IMPORTANT

index.json is ONLY a manifest.

It is NOT an image description.

Never generate prompts directly from index.json.

Never merge multiple image prompts into index.json.

Its purpose is ONLY to:

- discover all image description files
- validate processing completeness
- generate the final output index.json required by this workflow

---

# Reconstruction Objective

Do NOT summarize the description JSON.
Treat the JSON as semantic evidence describing an existing photograph.
Your objective is to reconstruct the original image as faithfully as possible.
The generated prompt should maximize reconstruction fidelity instead of creativity.
When information is missing, infer only realistic photographic properties.
Never invent new semantic content.

---

# Semantic Fidelity Rules

The following MUST remain identical across every variant.

## Subject

- identity
- number of people
- gender if identifiable
- age group if identifiable
- clothing
- hairstyle
- facial characteristics
- accessories

## Scene

- environment
- location
- important objects
- object relationships
- architecture
- landscape
- landmarks

## Composition

- primary subject
- major scene arrangement
- important foreground objects
- important background objects

Never introduce:

- new people
- new animals
- new buildings
- new vehicles
- new objects
- new weather events
- new scenery

# Variant Generation

Generate N variants where N is determined by the num_variants field in {MEDIA_CONFIG} (default 4).

Variant 1

Faithful reconstruction

Closest possible recreation of the original photograph.

Variant 2

Cinematic interpretation

More dramatic framing, cinematic lighting, stronger visual storytelling.

Variant 3

Fine Art interpretation

Elegant composition, artistic atmosphere, premium gallery photography style.

Variant 4

Epic Landscape / Environmental interpretation

Large sense of scale, environmental storytelling, immersive composition.

If num_variants > 4, continue with additional variants following the same pattern:
- Each additional variant should be visually distinct
- Vary camera technique, lighting, composition, and atmosphere
- Maintain semantic fidelity to the original scene

---

# Variant Diversity Rules

Every variant must preserve semantic fidelity.

However each variant should maximize photographic diversity.

Across all five variants intentionally vary combinations of:

- camera position
- camera height
- camera distance
- framing
- perspective
- focal length
- aperture
- depth of field
- lighting direction
- lighting intensity
- atmosphere
- weather intensity (only if consistent with original)
- color grading
- photographic style

Do NOT create variants by changing only one parameter.

Each variant should look like it was photographed by a different professional photographer.

Every variant should feel visually distinct while still clearly depicting the same original scene.

Do not reuse the same sentence structure between variants.

Rewrite each prompt independently.

# Output Rules

Output ONLY the required JSON files to disk.

Do NOT explain your reasoning.

Preserve existing workflow.

## Output Filename Convention

For each input description JSON, create an output file with `_prompts` suffix:

Input:  step_01/image_001.json  →  Output: step_02/image_001_prompts.json
Input:  step_01/beach_sunset.json  →  Output: step_02/beach_sunset_prompts.json

The output JSON filename must be: `<input_stem>_prompts.json`

## Index.json Structure

After processing all images, generate an index.json in step_02/ with this structure:

```json
{
  "step": "generate_prompts",
  "files": [
    {"input": "step_01/image_001.json", "output": "step_02/image_001_prompts.json"},
    {"input": "step_01/image_002.json", "output": "step_02/image_002_prompts.json"}
  ]
}
```

# CRITICAL: Output Mechanism

You MUST use your file-writing tools to create actual files on disk. Do NOT put artifact data in the meta.json result field -- the result field is for status and summary information ONLY.

Required file outputs:
1. Individual variant JSONs: {STEP_02_DIR}/<image_stem>_prompts.json for each input description
2. Index file: {STEP_02_DIR}/index.json listing all input-to-output mappings

Your meta.json result field should contain only:
- status: "complete" or "error"
- remark: brief summary (e.g., "Generated 4 variants each for 5 descriptions, wrote 5 JSONs + index")
- Do NOT include the full JSON data in the result field

In the artifacts field of meta.json, you MUST report:
- PROMPT_VARIANTS: the absolute path to the index.json file you wrote
