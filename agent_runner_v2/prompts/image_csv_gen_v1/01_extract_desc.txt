TASK
Scan all images in {IMAGE_FOLDER} (PNG, JPG, WEBP files).
For each image, read it and produce a structured visual description covering the image's core subject, mood, composition, lighting, style, color palette, and animatable elements.

DESCRIPTION FORMAT (MANDATORY)
For EACH image, save a JSON file named {image_stem}_desc.json in the same {IMAGE_FOLDER} directory.
The JSON must contain EXACTLY these keys:
- image_filename: original filename (e.g., "photo1.png")
- image_stem: filename without extension (e.g., "photo1")
- subject: detailed description of main visual elements, focal points, and recognizable identity
- mood: emotional tone, atmosphere, and cinematic feeling
- composition: framing, depth layers (foreground/midground/background), spatial arrangement, and vertical flow considerations
- lighting: quality, direction, color temperature, and atmospheric illumination
- style: artistic style, texture, rendering approach, and visual treatment
- color_palette: dominant and accent colors with their emotional associations
- animatable_elements: objects or effects that could move in video (e.g., hair swaying, fabric drifting, mist rolling, gentle blinking, soft light shifts, foliage movement)

ANALYSIS GUIDELINES
- Be specific and vivid — avoid generic descriptions like "a person standing"
- Capture the unique visual identity that makes this image distinct
- Note any vertical/portrait composition characteristics (headroom, negative space, full-height framing)
- Identify parallax potential: distinct foreground/midground/background layers at different depths
- List 2-4 specific animatable elements that would work naturally with the scene

OUTPUT INSTRUCTIONS

1. Read the image using your file reading tools
2. Produce the structured description following the format above
3. Save the JSON to: {IMAGE_FOLDER}/{image_stem}_desc.json
