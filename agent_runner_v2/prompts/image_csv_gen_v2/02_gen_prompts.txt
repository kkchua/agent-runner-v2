SINGLE SCENE LOCK — READ AND APPLY BEFORE WRITING ANY PROMPT
================================================================================

EVERY prompt describes ONE continuous camera view of ONE unified scene.
This rule overrides all other structural guidance.

BEFORE writing each prompt, answer these three questions internally:
1. Can this entire description be captured in ONE continuous camera frame?
2. Is there only ONE main subject, with supporting elements connected by
   spatial depth rather than panel separation?
3. Would a viewer see ONE coherent scene — not multiple stacked scenes?

If ANY answer is NO — rewrite until all answers are YES.

FORBIDDEN PATTERNS — NEVER use these:
✗ Multi-panel / collage / split-screen
✗ Multi-angle or multi-viewpoint in one prompt
✗ Diptych / triptych / top-bottom / left-right scene splits
✗ Picture-in-picture or inset descriptions
✗ Combining a closeup of one element with a wide shot of another
✗ Describing the same subject from two different distances in one prompt

CORRECT APPROACH:
- Pick ONE vantage point
- Let all other elements exist as natural spatial depth within that view
- Express depth through continuous spatial flow, not labeled zones

t2i_prompt1 RULES — WAN 2.2 T2V BASE PROMPT (CHINESE)
================================================================================

Length: 50–300 Chinese characters (字)

This single-scene declaration MUST appear at the start before any other content.
Placing it at the end is insufficient — the model must receive it first.

STRUCTURE (build in this order as one fluent paragraph after the opening):

0. STYLE DECLARATION (10–20 字):
   Explicitly state the rendering style FIRST, before all other content.
   Must include an anti-realism anchor phrase.
   Pattern: {RENDERING_STYLE}，非写实渲染，{style_texture_descriptor}
   Examples:
     卡通风格，非写实渲染，手绘线条质感
     二维动画风格，非照片真实，平涂色块质感
     日式动漫风格，非摄影渲染，赛璐珞上色风格

1. CAMERA DIRECTION (verbatim from Camera Direction Pool):
   Immediately after the opening declaration.

2. SUBJECT & SCENE — write as continuous spatial flow (60–90 字):
   Describe the main subject and environment as ONE flowing description.
   Do NOT use explicit zone labels (前景/中景/远景).
   Instead, use natural spatial language:
     透过…望向… | 在…背后隐约可见… | 绕过…延伸至… | 从…到…的空间中
   All depth layers must exist but flow naturally into each other,
   not be listed as separate labeled sections.

3. LIGHTING & ATMOSPHERE (30–40 字):
   Apply selected Variation Engine values:
   - Time of day, weather, color temperature
   - How light interacts with the subject surface
   - Atmospheric quality

4. MOTION & ANIMATION (20–30 字):
   2–3 subtle natural motions consistent with camera direction:
   - Subject motion, environmental motion, light motion
   All motions must align with the camera direction axis.

5. MOOD & CINEMATIC TONE (20–30 字):
   Emotional register and cinematic quality.
   Cultural or seasonal resonance if applicable.

DIRECTIONAL SEMANTIC LOCK:
All spatial and motion language MUST match the camera direction:
- 向前推进 → subject grows larger, background converges
- 向后拉远 → scene widens, subject recedes
- 向左/右横移 → elements scroll laterally
- 向上仰拍 → sky fills frame progressively
- 向下俯拍 → ground fills frame progressively

STRICT UNIDIRECTIONAL ENFORCEMENT:
Camera travels ONE direction only.
NO reversing, backtracking, oscillating, looping, or returning.

PARALLAX — express implicitly through speed language:
Near elements move faster. Far elements move slower.
Do not label zones — convey this through descriptive rhythm.

SUSTAINED MOTION CUES (include at least one):
持续推进 | 不间断单轴运动 | 平稳前行不偏转 | 从第一帧到最后一帧保持方向一致
