Objective

Review the staged Layer 2 platform core constitution set and decide whether it is acceptable for deterministic validation.

Layer Boundary

Forbidden Content

Reject if the staged set contains:

- Layer 1 governance redefinition or contradiction
- platform standards containing bundle-specific outputs or examples presented as platform-wide rules
- required permanent documents missing
- platform identity missing or unclear (`agent-runner-v2`)
- metadata values violating Layer 1 baseline
- evidence artifacts presented as permanent platform standards
- missing mandatory sections in a permanent document
- operational bootstrap mechanics or repository setup instructions
- a document map that omits {L2_PLATFORM_INDEX} from the six-document permanent set
- lifecycle-state misuse such as published/active values in staged docs

Review Decision

- Produce an explicit decision: approved or rejected.
- Always write a review file to {REVIEW_FILE_SUGGESTED}.
- Cite offending text directly for every rejection finding.
- If approved, summarize briefly why the set is ready for deterministic validation.

Output Instructions

Write the review file with these sections:

- `Decision`

- `Structure Findings`
