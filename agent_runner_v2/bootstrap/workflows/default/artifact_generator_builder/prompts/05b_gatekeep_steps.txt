# Gatekeep Tasks

1. **Routing Validity** -- No cycles, no dangling references:
   - All onsuccess targets exist
   - All on_reject_refine targets exist
   - No infinite loops

2. **Artifact Flow** -- All artifacts produced before consumed:
   - No step references undefined artifacts
   - All required_inputs are produced by prior steps
   - result_meta_key matches produces

3. **Completeness** -- All functionality covered:
   - All runtime impl steps are represented
   - All artifacts from contract are produced
   - Review loops are properly configured

4. **Abstract Step Interface Mapping** (BASE_COMPOSITION_STANDARD Section 13.8):
   - Each step in the sequence maps to an abstract step interface from the composition spec
   - Step names match the abstract interface names
   - Step input/output contracts match the abstract interface declarations

5. **Component Mapping** (BASE_COMPOSITION_STANDARD Section 13.8):
   - Prompt-driven steps reference prompt templates from the correct location (shared prompts/ or impl-specific impls/{name}/prompts/)
   - Action-driven steps reference registered action functions
   - The default implementation's component mapping covers all steps
