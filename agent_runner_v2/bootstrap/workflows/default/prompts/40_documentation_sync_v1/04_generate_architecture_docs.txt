## 1. Execution Modes Overview
Document the three main execution modes:
- Local run mode (ukbe-run-agent run)
- Backend worker mode (ukbe-run-agent worker)
- Daemon mode (ukbe-run-agent daemon)

## 2. Local Execution Flow
Step-by-step flow:
1. CLI parses arguments
2. Load workflow bundle
3. Resolve job (existing or new)
4. For each step:
   - Build context from state
   - Render prompt from template
   - Invoke coder with rendered prompt
   - Read meta.json sidecar
   - Validate artifacts
   - Route to next step
5. Complete when all steps done

Include ASCII diagram showing the flow.

## 3. Backend Worker Flow
Step-by-step flow:
1. Register worker with backend
2. Poll for available work
3. Claim step run
4. Invoke execute-step subprocess
5. Submit result to backend
6. Repeat

## 4. Daemon Supervision Flow
How the daemon manages child processes:
- Heartbeat management
- Child process lifecycle
- Workstation-level supervision

## 5. Workflow Step Execution
Detailed flow for a single step:
- Preflight checks
- Prompt rendering
- Coder invocation
- Sidecar validation
- Result routing (approve/reject/loop)

## 6. Review Loop Flow
How review and refinement works:
- Review step generates review file
- If rejected, refine step updates artifact
- Loop back to review
- Max iterations handling

## 7. Failure Routing Flow
How failures are handled:
- Exception classification
- Retry logic
- Human intervention escalation
- Job state updates

## 8. Documentation Sync Flow
How documentation is kept in sync:
- Codebase scan
- Module doc generation
- Inventory update
- Change impact recording
