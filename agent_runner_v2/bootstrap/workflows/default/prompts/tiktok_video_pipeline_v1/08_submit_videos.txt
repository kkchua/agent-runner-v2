================================================================================
TASK
================================================================================

Submit all I2V (image-to-video) prompts to ComfyUI for video generation.

================================================================================
INPUT
================================================================================

1. Read the image submission result from {IMAGE_SUBMIT_RESULT_PATH} to get the generated image paths/job IDs.
2. Read the approved workflow from {WORKFLOW_JSON_PATH} to get the I2V prompts for each scene.

================================================================================
SUBMISSION FORMAT
================================================================================

For EACH scene (NOT thumbnail), create a submission entry with:
{
  "video_filename": "scene_<NN>_video.mp4",
  "input_image": "<path to generated image from IMAGE_SUBMIT_RESULT>",
  "i2v_prompt": "<the scene's i2v_prompt value>",
  "duration_seconds": 8,
  "workflowKey": "QWEN/Image_QWEN_PA_Studio-540x960-01-dev"
}

Note: Thumbnail does NOT get an I2V submission — only scenes 1 through N.

================================================================================
SUBMISSION PROCESS
================================================================================

1. Load the ComfyUI configuration from: {PACKAGE_ROOT}/comfyui_config.json
   - Read credentials from the environment variables specified in the config

2. Authenticate:
   POST {COMFYUI_BASE_URL}/api/v1/auth/login
   Body: {"email": "<from env>", "password": "<from env>"}
   Response: {"token": "JWT..."}

3. For each I2V entry:
   a. Wait for the corresponding image generation to complete (poll job status)
   b. Retrieve the generated image path from the completed job
   c. POST {COMFYUI_BASE_URL}/api/v1/agent-studio/execute
      Body: {"workflow_key": "<workflowKey>", "inputs": <entry with input_image>, "test_mode": false}
      Header: Authorization: Bearer <token>
   d. Record the job_id from the response (or error message if failed)
   e. Wait {COMFYUI_DELAY_SECONDS} seconds before the next submission

4. After all submissions, write a summary to {VIDEO_SUBMIT_RESULT_PATH}

================================================================================
RESULT FORMAT
================================================================================

Write the submission result summary to: {VIDEO_SUBMIT_RESULT_PATH}

{
  "total_submissions": <N>,
  "successful": <M>,
  "failed": <K>,
  "entries": [
    {
      "scene_number": 1,
      "video_filename": "scene_01_video.mp4",
      "input_image": "<generated image path>",
      "job_id": "<job_id or error>",
      "status": "submitted" | "failed"
    }
  ],
  "workflow_key_used": "QWEN/Image_QWEN_PA_Studio-540x960-01-dev"
}

================================================================================
submit_videos COMPLETION RULE (MANDATORY)
================================================================================

You may return status: "APPROVED" only after all of the following are true:
- all I2V prompts have been submitted to the ComfyUI API
- the submission result summary has been written to {VIDEO_SUBMIT_RESULT_PATH}
- If the submission was not completed successfully, you MUST return REJECTED.

================================================================================
ABSOLUTE OUTPUT RULE (NON-NEGOTIABLE)
================================================================================

You are NOT a chat assistant.
You are a strict JSON generator.

Return ONLY valid JSON.
Do NOT explain.
Do NOT wrap in markdown.
Do NOT add any text before or after the JSON.
Do NOT wrap the final JSON in ```json fences.

Required JSON schema:
{
  "status": "APPROVED | REJECTED",
  "remark": "<short summary of result>",
  "artifacts": {
    "IMAGE_SUBMIT_RESULT": null,
    "VIDEO_SUBMIT_RESULT": null,
    "AUDIO_SUBMIT_RESULT": null,
    "FINAL_VIDEO": null
  }
}

Rules for the artifacts object:
- Include ONLY artifact keys produced or updated by this step.
- Use repository-relative paths.
- Do not invent paths that were not created or updated.
- If submission fails entirely, return status "REJECTED" with "artifacts": {}.
- For approval, artifacts.VIDEO_SUBMIT_RESULT is mandatory.

Required execution sequence:
1. Read the image submission result from {IMAGE_SUBMIT_RESULT_PATH}.
2. Read the workflow from {WORKFLOW_JSON_PATH}.
3. For each scene, pair the generated image with its I2V prompt.
4. Authenticate to the ComfyUI API.
5. Submit each I2V entry, tracking success/failure.
6. Write the submission summary to {VIDEO_SUBMIT_RESULT_PATH}.
7. Return the final JSON.
