================================================================================
TASK
================================================================================

Compose the final TikTok video by stitching together all generated assets through a ComfyUI composition workflow.

================================================================================
INPUT
================================================================================

1. Read the image submission result from {IMAGE_SUBMIT_RESULT_PATH} — contains generated image paths
2. Read the video submission result from {VIDEO_SUBMIT_RESULT_PATH} — contains generated video clip paths
3. Read the audio submission result from {AUDIO_SUBMIT_RESULT_PATH} — contains generated audio file paths
4. Read the approved workflow from {WORKFLOW_JSON_PATH} — contains transitions, timing, and style_guide

================================================================================
COMPOSITION FORMAT
================================================================================

Create a composition entry with all assets:
{
  "output_filename": "final_tiktok_video.mp4",
  "aspect_ratio": "9:16",
  "thumbnail_image": "<path to generated thumbnail image>",
  "scene_clips": [
    {
      "scene_number": 1,
      "video_clip": "<path to scene 1 video>",
      "audio_clip": "<path to scene 1 voiceover audio>",
      "duration_seconds": <from workflow>,
      "transition": "<from workflow: fade|dissolve|cut|wipe>"
    }
  ],
  "style_guide": {
    "visual_style": "<from workflow>",
    "color_palette": "<from workflow>",
    "lighting_style": "<from workflow>",
    "camera_style": "<from workflow>"
  },
  "workflowKey": "QWEN/Video_Compose_Studio-960x540-01-dev"
}

Note: The final scene should have transition: "none" (no transition after the last scene).

================================================================================
SUBMISSION PROCESS
================================================================================

1. Load the ComfyUI configuration from: {PACKAGE_ROOT}/comfyui_config.json
   - Read credentials from the environment variables specified in the config

2. Authenticate:
   POST {COMFYUI_BASE_URL}/api/v1/auth/login
   Body: {"email": "<from env>", "password": "<from env>"}
   Response: {"token": "JWT..."}

3. Wait for all video and audio generation jobs to complete:
   - Poll job status for each video job from VIDEO_SUBMIT_RESULT
   - Poll job status for each audio job from AUDIO_SUBMIT_RESULT
   - Retrieve output file paths from completed jobs

4. Submit the composition job:
   POST {COMFYUI_BASE_URL}/api/v1/agent-studio/execute
   Body: {"workflow_key": "<workflowKey>", "inputs": <composition entry>, "test_mode": false}
   Header: Authorization: Bearer <token>

5. Wait for composition job to complete and retrieve final video path

6. Write the result to {FINAL_VIDEO_PATH}

================================================================================
RESULT FORMAT
================================================================================

Write the composition result to: {FINAL_VIDEO_PATH}

{
  "final_video_path": "<path to final composed video>",
  "duration_seconds": <total duration>,
  "aspect_ratio": "9:16",
  "scene_count": <N>,
  "thumbnail_path": "<path to thumbnail image>",
  "composition_job_id": "<job_id>",
  "status": "completed" | "failed",
  "error": null | "<error message if failed>"
}

================================================================================
compose_final COMPLETION RULE (MANDATORY)
================================================================================

You may return status: "APPROVED" only after all of the following are true:
- all video and audio jobs have completed successfully
- the composition job has been submitted and completed
- the final video has been saved to {FINAL_VIDEO_PATH}
- the meta.json sidecar has been written to {FINAL_VIDEO_METAJSON}
- If the composition was not completed successfully, you MUST return REJECTED.

Critical: meta.json sidecar is REQUIRED
- The runner reads the result from the sidecar file, NOT from your JSON output.
- Sidecar path: {FINAL_VIDEO_METAJSON}
- Sidecar structure (exact):
{
  "schema_version": "v2",
  "coder_result": {
    "status": "APPROVED" | "REJECTED",
    "remark": "Composed final TikTok video: <duration>s, <N> scenes",
    "artifacts": {
      "FINAL_VIDEO": "{FINAL_VIDEO_PATH}"
    },
    "recorded_at": "<current ISO timestamp>"
  }
}
- Use write_file tool to create the sidecar immediately after writing the result.
- You MUST verify the sidecar exists on disk before returning.

================================================================================
ABSOLUTE OUTPUT RULE (NON-NEGOTIABLE)
================================================================================

You are NOT a chat assistant.
You are a strict JSON generator.

Return ONLY valid JSON.
Do NOT explain.
Do NOT wrap in markdown.
Do NOT add any text before or after the JSON.
Do NOT wrap the final JSON in ```json fences.

Required JSON schema:
{
  "status": "APPROVED | REJECTED",
  "remark": "<short summary of result>",
  "artifacts": {
    "IMAGE_SUBMIT_RESULT": null,
    "VIDEO_SUBMIT_RESULT": null,
    "AUDIO_SUBMIT_RESULT": null,
    "FINAL_VIDEO": null
  }
}

Rules for the artifacts object:
- Include ONLY artifact keys produced or updated by this step.
- Use repository-relative paths.
- Do not invent paths that were not created or updated.
- If composition fails, return status "REJECTED" with "artifacts": {}.
- For approval, artifacts.FINAL_VIDEO is mandatory.

Required execution sequence:
1. Read all submission results (IMAGE_SUBMIT_RESULT, VIDEO_SUBMIT_RESULT, AUDIO_SUBMIT_RESULT).
2. Read the workflow from {WORKFLOW_JSON_PATH}.
3. Wait for all video and audio jobs to complete.
4. Build the composition entry with all asset paths and transitions.
5. Authenticate to the ComfyUI API.
6. Submit the composition job.
7. Wait for composition to complete.
8. Write the final video result to {FINAL_VIDEO_PATH}.
9. Write the meta.json sidecar to {FINAL_VIDEO_METAJSON}.
10. Verify the sidecar exists on disk.
11. Return the final JSON.

- [ ] All voiceover audio files are present and playable
- [ ] Transitions between scenes match the workflow specification
