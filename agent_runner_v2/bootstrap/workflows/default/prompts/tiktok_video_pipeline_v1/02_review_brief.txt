================================================================================
TASK
================================================================================

Review the structured visual brief in {BRIEF_JSON}.
Read the brief and validate it against quality criteria.

================================================================================
REVIEW CRITERIA
================================================================================

Verify the following for the brief:

1. STRUCTURAL VALIDATION
- JSON is valid and parseable
- All required keys are present: input_type, subject, mood, visual_style, color_palette, lighting_direction, target_audience, scene_count, key_elements, tiktok_hook_direction, animatable_elements, composition_notes
- input_type is one of: "image", "text", "theme"
- scene_count is a positive integer (default 4, max 8)
- key_elements is a non-empty array
- animatable_elements is a non-empty array with at least 3 items

2. CONTENT QUALITY
- subject is specific and vivid (not generic like "a person standing")
- mood conveys clear emotional tone
- visual_style is a defined artistic direction
- color_palette specifies both dominant and accent colors
- lighting_direction is actionable for image generation
- tiktok_hook_direction is compelling and scroll-stopping

3. TIKTOK OPTIMIZATION
- Content is suitable for vertical 9:16 format
- target_audience is clearly defined
- Visual concept has bold focal points for mobile viewing
- Animatable elements are natural and cinematic

4. CONSISTENCY CHECK
- All elements align with the original user input intent
- Color palette matches the mood
- Visual style is coherent with subject and mood

================================================================================
DECISION FORMAT
================================================================================

Write the review to: {REVIEW_FILE_PATH}

The review file must contain:
- A validation checklist with pass/fail for each criterion
- Specific remarks for any failed criteria
- A final decision: APPROVED or REJECTED
- If REJECTED: list specific issues that need to be fixed
