================================================================================
REVIEW CRITERIA
================================================================================

1. STRUCTURAL VALIDATION
- JSON is valid and parseable
- workflow_version is present and equals "1.0"
- platform equals "TikTok"
- scene_count matches the actual number of scenes in the array
- All required top-level keys present: workflow_version, platform, scene_count, project, thumbnail, scenes, style_guide, metadata

2. PROJECT OBJECT VALIDATION
- title: non-empty string, 5-8 words
- tiktok_hook: non-empty string, under 10 words
- caption: non-empty string with 2-3 sentences and 3-5 hashtags
- video_angle: non-empty string, 1-2 sentence global narrative overview

3. THUMBNAIL VALIDATION
- t2i_prompt: non-empty string
- Follows 6-layer hierarchy (style declaration first)
- Specifies vertical 9:16 composition
- Contains texture density descriptions
- Ends with positive quality constraints

4. SCENE VALIDATION (for EACH scene)
- scene_number: sequential starting from 1
- scene_type: one of "hook", "escalation", "turning_point", "resolution"
- Scene 1 must be "hook", last scene must be "resolution"
- t2i_prompt: follows 6-layer hierarchy, 100+ characters
- i2v_prompt: contains all 5 components (camera motion, environmental animation, subject motion, emotional beat, transition)
- voiceover: max 15 words, creates curiosity
- emotional_beat: one of "discovery", "anticipation", "wonder", "tension", "release", "mystery", "calm"
- transition: one of "fade", "dissolve", "cut", "wipe", "none" (last scene must be "none")

5. PROMPT QUALITY VALIDATION
- T2I prompts begin with style declaration ("A cinematic 3D scene in...")
- T2I prompts contain texture density (surfaces, materials, environmental textures)
- T2I prompts use spatial precision ("in the foreground", "behind", etc.)
- T2I prompts end with quality constraints ("razor sharp focus, pristine imaging...")
- I2V prompts specify single camera direction (no combining multiple)
- I2V prompts contain sustained motion cues
- No bidirectional/reverse/loop language in I2V prompts

6. CONSISTENCY VALIDATION
- All scenes maintain same visual_style (from style_guide)
- All scenes maintain same color_palette (from style_guide)
- Each scene has DIFFERENT camera angle
- Each scene has DIFFERENT primary camera movement
- Transitions logically connect consecutive scenes
- Voiceovers advance narrative (no repetition across scenes)

7. STYLE_GUIDE VALIDATION
- visual_style: non-empty, consistent across scenes
- color_palette: non-empty, matches project mood
- lighting_style: non-empty, actionable
- camera_style: non-empty, describes movement approach

8. METADATA VALIDATION
- estimated_duration_seconds: positive integer, 20-120 range
- aspect_ratio: equals "9:16"
- target_audience: non-empty string
- hashtags: array of 3-5 strings
