================================================================================
TASK
================================================================================

Submit all T2I (text-to-image) prompts from the approved workflow to ComfyUI for image generation.

================================================================================
INPUT
================================================================================

Read the approved workflow from {WORKFLOW_JSON_PATH}.

Extract T2I prompts for:
1. Thumbnail image (thumbnail.t2i_prompt)
2. Each scene image (scenes[i].t2i_prompt)

================================================================================
SUBMISSION FORMAT
================================================================================

For EACH T2I prompt, create a submission entry with:
{
  "image_filename": "<scene identifier>.png",
  "t2i_prompt": "<the t2i_prompt value>",
  "negative_prompt": "low quality, blurry, distorted, text, watermark, logo",
  "workflowKey": "QWEN/Image_QWEN_PA_Studio-540x960-01-dev"
}

Filename rules:
- thumbnail → "00_thumbnail.png"
- scene 1 → "01_scene_01.png"
- scene 2 → "02_scene_02.png"
- etc.

================================================================================
SUBMISSION PROCESS
================================================================================

1. Load the ComfyUI configuration from: {PACKAGE_ROOT}/comfyui_config.json
   - This file contains base_url, email_env, password_env, delay_seconds
   - Read credentials from the environment variables specified in the config

2. Authenticate:
   POST {COMFYUI_BASE_URL}/api/v1/auth/login
   Body: {"email": "<from env>", "password": "<from env>"}
   Response: {"token": "JWT..."}

3. For each T2I entry:
   a. POST {COMFYUI_BASE_URL}/api/v1/agent-studio/execute
      Body: {"workflow_key": "<workflowKey>", "inputs": <entry>, "test_mode": false}
      Header: Authorization: Bearer <token>
   b. Record the job_id from the response (or error message if failed)
   c. Wait {COMFYUI_DELAY_SECONDS} seconds before the next submission

4. After all submissions, write a summary to {IMAGE_SUBMIT_RESULT_PATH}

================================================================================
RESULT FORMAT
================================================================================

Write the submission result summary to: {IMAGE_SUBMIT_RESULT_PATH}

{
  "total_submissions": <N>,
  "successful": <M>,
  "failed": <K>,
  "entries": [
    {
      "image_filename": "00_thumbnail.png",
      "job_id": "<job_id or error>",
      "status": "submitted" | "failed"
    }
  ],
  "workflow_key_used": "QWEN/Image_QWEN_PA_Studio-540x960-01-dev"
}

================================================================================
submit_images COMPLETION RULE (MANDATORY)
================================================================================

You may return status: "APPROVED" only after all of the following are true:
- all T2I prompts have been submitted to the ComfyUI API
- the submission result summary has been written to {IMAGE_SUBMIT_RESULT_PATH}
- If the submission was not completed successfully, you MUST return REJECTED.

================================================================================
ABSOLUTE OUTPUT RULE (NON-NEGOTIABLE)
================================================================================

You are NOT a chat assistant.
You are a strict JSON generator.

Return ONLY valid JSON.
Do NOT explain.
Do NOT wrap in markdown.
Do NOT add any text before or after the JSON.
Do NOT wrap the final JSON in ```json fences.

Required JSON schema:
{
  "status": "APPROVED | REJECTED",
  "remark": "<short summary of result>",
  "artifacts": {
    "IMAGE_SUBMIT_RESULT": null,
    "VIDEO_SUBMIT_RESULT": null,
    "AUDIO_SUBMIT_RESULT": null,
    "FINAL_VIDEO": null
  }
}

Rules for the artifacts object:
- Include ONLY artifact keys produced or updated by this step.
- Use repository-relative paths.
- Do not invent paths that were not created or updated.
- If submission fails entirely, return status "REJECTED" with "artifacts": {}.
- For approval, artifacts.IMAGE_SUBMIT_RESULT is mandatory.

Required execution sequence:
1. Read the workflow from {WORKFLOW_JSON_PATH}.
2. Extract all T2I prompts (thumbnail + scenes).
3. Authenticate to the ComfyUI API.
4. Submit each T2I entry, tracking success/failure.
5. Write the submission summary to {IMAGE_SUBMIT_RESULT_PATH}.
6. Return the final JSON.
