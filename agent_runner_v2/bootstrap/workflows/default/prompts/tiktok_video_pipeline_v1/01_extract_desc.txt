================================================================================
INPUT HANDLING
================================================================================

IF user input is an IMAGE:
- Read the image file
- Extract: subject, mood, composition, lighting, style, color palette

- Note vertical/portrait composition characteristics

IF user input is TEXT or THEME:
- Parse the description for creative intent
- Determine: subject, mood, visual style, color palette, target audience
- Identify key visual elements that should appear

ANALYSIS GUIDELINES
================================================================================

- List 5-8 animatable elements that would work naturally with the scene
- Consider TikTok virality: bold visuals, clear focal points, emotional resonance
- Default scene_count to 4 unless user explicitly requests otherwise
