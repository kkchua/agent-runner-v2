TASK
Submit all generated prompt entries to the ComfyUI API for processing.

INPUT
The run directory {IMAGE_CSV_RUN_DIR} contains JSON files produced by gen_prompts.
Each JSON file has an array of entries with:
- image_filename
- t2i_prompt1
- t2i_prompt2
- negative_prompt
- workflowKey (the ComfyUI workflow identifier, e.g. "QWEN/Image_QWEN_PA_Studio-540x960-01-dev")

SUBMISSION PROCESS
1. Load the ComfyUI configuration from: {PACKAGE_ROOT}/comfyui_config.json
   - This file contains base_url, email_env, password_env, delay_seconds
   - Read credentials from the environment variables specified in the config

2. Authenticate:
   POST {COMFYUI_BASE_URL}/api/v1/auth/login
   Body: {"email": "<from env>", "password": "<from env>"}
   Response: {"token": "JWT..."}

3. For each entry in each JSON file:
   a. Use workflowKey from the entry (or {WORKFLOW_KEY_OVERRIDE} if provided and non-empty)
   b. POST {COMFYUI_BASE_URL}/api/v1/agent-studio/execute
      Body: {"workflow_key": "<key>", "inputs": <entry>, "test_mode": false}
      Header: Authorization: Bearer <token>
   c. Record the job_id from the response (or error message if failed)
   d. Wait {COMFYUI_DELAY_SECONDS} seconds before the next submission

4. After all submissions, write a summary to {IMAGE_CSV_SUBMIT_RESULT_PATH}

WORKFLOW_KEY OVERRIDE
- If {WORKFLOW_KEY_OVERRIDE} is non-empty, use it instead of the workflowKey from each entry
- If {WORKFLOW_KEY_OVERRIDE} is empty and an entry has no workflowKey, skip that entry and record the error

submit_prompts completion rule (MANDATORY)
- You may return `status: "APPROVED"` only after all of the following are true:
  - all JSON entries have been submitted to the ComfyUI API
  - the submission result summary file has been written to {IMAGE_CSV_SUBMIT_RESULT_PATH}
  - the meta.json sidecar has been written to {IMAGE_CSV_SUBMIT_RESULT_METAJSON}
- If the submission was not completed successfully, you MUST return `REJECTED`.

Critical: meta.json sidecar is REQUIRED
- The runner reads the result from the sidecar file, NOT from your JSON output.
- Sidecar path: {IMAGE_CSV_SUBMIT_RESULT_METAJSON}
- Sidecar structure (exact):
  {
    "schema_version": "v2",
    "coder_result": {
      "status": "APPROVED" | "REJECTED",
      "remark": "Submitted N entries: M succeeded, K failed",
      "artifacts": {
        "IMAGE_CSV_SUBMIT_RESULT": "{IMAGE_CSV_SUBMIT_RESULT_PATH}"
      },
      "recorded_at": "<current ISO timestamp>"
    }
  }
- Use write_file tool to create the sidecar immediately after writing the summary file.
- You MUST verify the sidecar exists on disk before returning.

ABSOLUTE OUTPUT RULE (NON-NEGOTIABLE)

You are NOT a chat assistant.
You are a strict JSON generator.

Return ONLY valid JSON.
Do NOT explain.
Do NOT wrap in markdown.
Do NOT add any text before or after the JSON.
Do NOT wrap the final JSON in ```json fences.

Required JSON schema:
{
  "status": "APPROVED | REJECTED",
  "remark": "<short summary of result>",
  "artifacts": {
    "IMAGE_DESC_FOLDER": null,
    "IMAGE_CSV_JSON": null,
    "IMAGE_CSV_CSV": null,
    "IMAGE_CSV_SUBMIT_RESULT": null,
    "REVIEW_FILE": null,
    "VALIDATION_FILE": null
  }
}

Rules for the artifacts object:
- Include ONLY artifact keys produced or updated by this step.
- Use repository-relative paths.
- Do not invent paths that were not created or updated.
- If submission fails entirely (no entries submitted), return status "REJECTED" with "artifacts": {}.
- For approval, `artifacts.IMAGE_CSV_SUBMIT_RESULT` is mandatory.

Required execution sequence:
1. Read all *.json files from {IMAGE_CSV_RUN_DIR}.
2. Authenticate to the ComfyUI API.
3. Submit each entry, tracking success/failure.
4. Write the submission summary to {IMAGE_CSV_SUBMIT_RESULT_PATH}.
5. Write the meta.json sidecar to {IMAGE_CSV_SUBMIT_RESULT_METAJSON}.
6. Verify the sidecar exists on disk.
7. Return the final JSON with status and artifacts.IMAGE_CSV_SUBMIT_RESULT.
