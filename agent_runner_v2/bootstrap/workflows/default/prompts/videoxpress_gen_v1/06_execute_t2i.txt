TASK
Execute Text-to-Image generation for all scenes using their T2I prompts.

INPUT:
- VIDEOWORKFLOW_FILE: Contains all scene text_to_image_prompts

EXECUTION STEPS:
================================================================================

For EACH scene in scenes array:
1. Extract scene_number and text_to_image_prompt
2. Execute T2I generation with full quality settings
3. Save generated image to GENERATED_IMAGES_FOLDER
4. Record generation metadata

IMAGE NAMING:
================================================================================

Save images as:
{GENERATED_IMAGES_FOLDER}/scene_{NN}_t2i.png

Where NN is zero-padded scene number (01, 02, etc.)

QUALITY REQUIREMENTS:
================================================================================

- Full resolution (no downsampling)
- Complete 6-Layer Hierarchy rendering
- All texture details as specified
- Proper aspect ratio (from workflow metadata)

COMFYUI INTEGRATION:
================================================================================

Use workflowKey from VIDEOWORKFLOW_FILE metadata.
Submit via ComfyUI API with:
- prompt: scene.text_to_image_prompt
- width/height: based on aspect_ratio
- steps: 20-30
- cfg: 7.0-8.0

OUTPUT:
================================================================================

{
  "status": "APPROVED|REJECTED",
  "remark": "Generated N T2I images",
  "artifacts": {
    "GENERATED_IMAGES_FOLDER": "path/to/images/folder/"
  },
  "scene_status": [
    {"scene": 1, "status": "success|failed", "filename": "scene_01_t2i.png"}
  ]
}
