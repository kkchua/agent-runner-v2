TASK
Generate voiceover audio for all scenes.

INPUT:
- VIDEOWORKFLOW_FILE: Contains voiceover_prompt for each scene

VOICEOVER GENERATION:
================================================================================

For EACH scene:
1. Extract scene_number and voiceover_prompt
2. Generate TTS audio using appropriate voice
3. Save to GENERATED_AUDIO_FOLDER

AUDIO NAMING:
================================================================================

Save audio as:
{GENERATED_AUDIO_FOLDER}/scene_{NN}_voiceover.mp3

Where NN is zero-padded scene number (01, 02, etc.)

VOICE SELECTION:
================================================================================

Based on platform and mood:
- TikTok: Energetic, punchy delivery
- YouTube: Calm, reflective tone
- Match emotional_beat from scene

TTS PARAMETERS:
================================================================================

- Speed: Normal (1.0x) or slightly slower for reflection
- Pitch: Natural, matching content mood
- Quality: High (44.1kHz, 128kbps+)

PROVIDERS:
================================================================================

Use one of:
- ElevenLabs (highest quality)
- OpenAI TTS
- Azure TTS
- Local TTS engine

OUTPUT:
================================================================================

{
  "status": "APPROVED|REJECTED",
  "remark": "Generated N voiceover files",
  "artifacts": {
    "GENERATED_AUDIO_FOLDER": "path/to/audio/folder/"
  },
  "scene_status": [
    {"scene": 1, "status": "success|failed", "filename": "scene_01_voiceover.mp3"}
  ]
}

Write meta.json sidecar with generation status.
