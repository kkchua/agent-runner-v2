TASK
Assemble final video from all generated assets.

INPUT:
- VIDEOWORKFLOW_FILE: Contains workflow metadata and scene transitions
- GENERATED_VIDEO_CLIPS: Contains scene_{NN}_i2v.mp4 files
- GENERATED_AUDIO_FOLDER: Contains scene_{NN}_voiceover.mp3 files

ASSEMBLY PROCESS:
================================================================================

1. For EACH scene in sequence:
   a. Load scene_{NN}_i2v.mp4
   b. Load scene_{NN}_voiceover.mp3
   c. Mix audio (voiceover + ambient from video)
   d. Apply transition from previous scene
   e. Append to final timeline

2. Apply final output settings:
   - Resolution based on aspect_ratio
   - Frame rate: 24 or 30 fps
   - Codec: H.264 for compatibility
   - Audio: AAC, stereo

TRANSITIONS:
================================================================================

Apply transitions from scene.transition:
- fade: Crossfade between scenes
- dissolve: Gradual dissolve
- cut: Hard cut
- wipe: Wipe transition
- glow: Bloom transition

AUDIO MIXING:
================================================================================

- Voiceover: Primary track, full volume
- Ambient (from I2V): Background, -12dB
- Duck ambient when voiceover plays
- Ensure consistent levels across scenes

FINAL OUTPUT:
================================================================================

Save to:
{FINAL_VIDEO_FILE}

Example: output/final_video.mp4

METADATA:
================================================================================

Embed in video:
- Title from content.project_title
- Description from content.description
- Keywords from metadata.keywords

OUTPUT JSON:
================================================================================

{
  "status": "APPROVED|REJECTED",
  "remark": "Assembled final video",
  "artifacts": {
    "FINAL_VIDEO_FILE": "path/to/final_video.mp4"
  },
  "video_info": {
    "duration": "60 seconds",
    "resolution": "1920x1080",
    "fps": 30,
    "file_size": "50MB"
  }
}

Return ONLY the JSON. No explanations.
