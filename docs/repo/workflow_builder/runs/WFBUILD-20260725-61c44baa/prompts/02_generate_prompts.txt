Objective

Scan the directory referenced by {STEP_01_DIR} for description JSON
files produced by the extract_descriptions step. For each description
JSON, generate N variant prompt sets (where N is read from the
num_variants field in {MEDIA_CONFIG}, defaulting to 4 if not
specified). Each variant must include a t2i_prompt1 field containing
a detailed English text-to-image prompt derived from the description
data. Save variant JSONs to {STEP_02_DIR} with filenames matching
the input description stems. After processing all descriptions,
archive the processed description JSONs by copying them to
{STEP_01_ARCHIVE} and removing them from {STEP_01_DIR}. Finally,
produce an index.json file in {STEP_02_DIR} listing all input-to-output
file mappings.

Reference Inputs

- Description JSONs directory: {STEP_01_DIR}
- Output variants directory: {STEP_02_DIR}
- Archive directory for processed descriptions: {STEP_01_ARCHIVE}
- Media configuration: {MEDIA_CONFIG}
- Governance docs: {GOVERNANCE_RUNTIME_ROOT}
- Platform docs: {PLATFORM_RUNTIME_ROOT}

Output Instructions

For each description JSON file found in {STEP_01_DIR}, read the
descriptions array and generate variant prompt sets. The number of
variants per description is determined by the num_variants field
in {MEDIA_CONFIG} (default 4).

Each variant must contain a t2i_prompt1 field that is a detailed,
descriptive English text-to-image prompt. The prompt should incorporate
the subject attributes, scene attributes, composition, lighting, style,
color palette, and mood from the description data. Prompts must be in
English. Prompts should be rich enough to guide an image generation
model to produce visually similar results to the source image.

Variant JSON structure:
{
  "mode": "BASE",
  "subject": "<image_stem from input description>",
  "variations": [
    {
      "t2i_prompt1": "<detailed English text-to-image prompt>",
      "image_filename": "<image_stem>_01.png",
      "image_url": ""
    },
    {
      "t2i_prompt1": "<detailed English text-to-image prompt>",
      "image_filename": "<image_stem>_02.png",
      "image_url": ""
    },
    {
      "t2i_prompt1": "<detailed English text-to-image prompt>",
      "image_filename": "<image_stem>_03.png",
      "image_url": ""
    },
    {
      "t2i_prompt1": "<detailed English text-to-image prompt>",
      "image_filename": "<image_stem>_04.png",
      "image_url": ""
    }
  ]
}

Each variant within the variations array must have:
- t2i_prompt1: A detailed English text prompt for image generation.
  Each variant should offer a different creative interpretation or
  emphasis while staying faithful to the source image description.
- image_filename: Output image filename following the pattern
  {stem}_NN.png where NN is two-digit zero-padded (01, 02, 03, etc.).
- image_url: Empty string (this field will be populated by the
  generate_images step).

After writing all variant JSONs to {STEP_02_DIR}:

1. Copy each processed description JSON file from {STEP_01_DIR} to
   {STEP_01_ARCHIVE}.
2. Remove each processed description JSON file from {STEP_01_DIR}.
3. Write an index.json file to {STEP_02_DIR} with this structure:
   {
     "step": "generate_prompts",
     "files": [
       {"input": "step_01/image001.json", "output": "step_02/image001.json"}
     ]
   }

All output must be ASCII-only JSON with UTF-8 encoding.

Artifacts

Write the output to: {PROMPT_VARIANTS}
