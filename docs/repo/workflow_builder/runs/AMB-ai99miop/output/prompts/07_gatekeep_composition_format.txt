# Objective

Gatekeep review of the composition format. Validate that it correctly
defines 8 binding rules, 6 workflow patterns, override mechanism,
placeholder resolution, and ordering rules. Produce APPROVED or
REJECTED verdict.

This step produces the GATEKEEP_COMPOSITION_FORMAT_FILE.

## Reference Inputs

Read the following files before producing any output:

- COMPOSITION_FORMAT_FILE: {COMPOSITION_FORMAT_FILE}
  Validate the complete composition format document.

## Validation Checklist

1. **Binding rules** -- Exactly 8 rules defined, one per component
   type: steps, roles, routing, prompts, artifacts, standard,
   variances, domain_specs.

2. **Workflow patterns** -- Exactly 6 patterns defined: action_only,
   prompt_driven, mixed, gatekeeper_pipeline, meta_workflow_builder,
   meta_meta_builder.

3. **Override mechanism** -- Complete with merge semantics, schema
   conformance rules, and examples.

4. **Placeholder resolution** -- 3 data sources, resolution order,
   unresolved handling defined.

5. **Ordering rules** -- Constraints for step_bindings documented.

6. **Composition validation** -- CV-001 through CV-010 present.

7. **Examples** -- At least 2 complete composition examples.

## Decision Rules

Return APPROVED if all checklist items pass.
Return REJECTED with specific findings.

## Self-Critic

- Did you verify each binding rule matches its component type?
- Did you check that all 6 workflow patterns are distinct?

## Output Instructions

Use file-writing tools to write the gatekeep verdict to:
{GATEKEEP_COMPOSITION_FORMAT_FILE}

Format: Markdown with YAML frontmatter.
Include APPROVED or REJECTED verdict.

ASCII-only content.

The result field in meta.json is for status summary ONLY.
