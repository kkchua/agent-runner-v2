Objective

Generate the Marketing Assets/Trending section artifact for the Product
Master. This section covers existing brand assets, visual asset
inventory, trending topics, and marketing-relevant knowledge derived
from the available source materials.

Layer Boundary

- This workflow belongs to Layer 3 and operates on top of the Layer 2
  platform contract.
- Generate only the Marketing Assets section content. Do not generate
  Product Information, Target Audience, Benefits, or Additional Sections.
- Treat Layer 1 governance and Layer 2 platform constitution as read-only
  reference inputs.

Reference Inputs

- Read the scan report to understand what source files are available:
  {SCAN_REPORT_FILE}
- Read the source directory for available product materials:
  {PRODUCT_SOURCE_DIR}
- Read Layer 1 governance documents for metadata standards:
  {GOVERNANCE_RUNTIME_ROOT}

Content Scope

Identify and document the marketing-relevant knowledge from the available
source materials. This section covers ONLY marketing asset inventory and
trending angles. Do not include factual product data, audience analysis,
benefits, or proposed additional sections. Do not produce campaign
execution plans, media buying strategies, or marketing deployment
schedules.

Required content domains:
- Existing brand assets found in inputs (logos, style guides, templates,
  brand guidelines)
- Visual asset inventory (product photos, lifestyle images, packaging
  images found in the source directory)
- Trending topics and angles relevant to the product (identified from
  source materials or URL content)
- Social media hooks and content ideas (suggested angles derived from
  source materials)
- Campaign theme suggestions (high-level themes, not execution plans)
- Influencer and partnership angles (potential collaboration directions)

Source File Guidance

Consult the scan report to determine which source files are available.
Source types may include: images, manuals, brochures, specifications,
documents, URL lists, and notes.

For URL lists, use the webfetch tool to retrieve and read URL content.
Images are critical for the visual asset inventory. Brochures and
marketing materials are key for brand asset identification. Notes may
contain campaign ideas or trending observations. Not all source types
will be present. Work only with the files that exist.

Knowledge Gap Handling

If information for a required content domain is not found in any source
file, represent it explicitly as a knowledge gap. Use the format:

  Not available from provided sources.

Do not fabricate brand assets or marketing data. Factual accuracy takes
priority over completeness.

Conflict Handling

If conflicting information is found across different source files,
explicitly note both sides with source attribution. Example:

  Brand color palette: Blue/white (per style guide PDF) vs
  Green/gold (per brochure). Discrepancy unresolved.

Output Instructions

- Write the generated content to the file at {MARKETING_ASSETS_FILE}.
- Use markdown format with a section heading.
- The output file must be ASCII-only (no em-dashes, curly quotes, or
  other Unicode characters).
- Use plain text section headings without formatting markup.
- Use the product slug ({SLUG}) to identify the product context.
- The result field in meta.json must contain a brief summary of what
  was generated. All document content must be written to the artifact
  file, not placed in the meta.json result field.

Forbidden Content

- Factual product specifications or dimensions
- Audience demographics or persona details
- Benefits or value proposition content
- Campaign execution plans, media schedules, or deployment strategies
- Additional section proposals
- Content not traceable to source files
