Objective

Generate the Target Audience section artifact for the Product Master.
This section covers audience insights and market positioning derived
from the available source materials.

Layer Boundary

- This workflow belongs to Layer 3 and operates on top of the Layer 2
  platform contract.
- Generate only the Target Audience section content. Do not generate
  Product Information, Benefits, Marketing Assets, or Additional Sections.
- Treat Layer 1 governance and Layer 2 platform constitution as read-only
  reference inputs.

Reference Inputs

- Read the scan report to understand what source files are available:
  {SCAN_REPORT_FILE}
- Read the source directory for available product materials:
  {PRODUCT_SOURCE_DIR}
- Read Layer 1 governance documents for metadata standards:
  {GOVERNANCE_RUNTIME_ROOT}

Content Scope

Identify and document the target audience for the product based on the
available source materials. This section covers ONLY audience and market
insights. Do not include factual product data, benefits, marketing assets,
or proposed additional sections.

Required content domains:
- Primary demographic profile (age range, gender, location, income level)
- Buyer personas (2-3 archetypes with name, background, motivations,
  and purchasing behavior)
- Use cases and scenarios (how and when the target audience uses the
  product)
- Market segment and positioning (where the product sits in the market)
- Psychographic indicators (values, interests, lifestyle factors
  relevant to the product)

Source File Guidance

Consult the scan report to determine which source files are available.
Source types may include: images, manuals, brochures, specifications,
documents, URL lists, and notes.

For URL lists, use the webfetch tool to retrieve and read URL content.
Brochures and marketing materials are particularly relevant for audience
insights. Notes and journal files may contain market observations.
Not all source types will be present. Work only with the files that exist.

Knowledge Gap Handling

If information for a required content domain is not found in any source
file, represent it explicitly as a knowledge gap. Use the format:

  Not available from provided sources.

Do not fabricate audience data or make unsupported demographic claims.
Factual accuracy takes priority over completeness.

Conflict Handling

If conflicting information is found across different source files,
explicitly note both sides with source attribution. Example:

  Target age range: 25-34 (per marketing brochure) vs 35-50 (per
  product notes). Discrepancy unresolved.

Output Instructions

- Write the generated content to the file at {TARGET_AUDIENCE_FILE}.
- Use markdown format with a section heading.
- The output file must be ASCII-only (no em-dashes, curly quotes, or
  other Unicode characters).
- Use plain text section headings without formatting markup.
- Use the product slug ({SLUG}) to identify the product context.
- The result field in meta.json must contain a brief summary of what
  was generated. All document content must be written to the artifact
  file, not placed in the meta.json result field.

Forbidden Content

- Factual product specifications or dimensions
- Benefits or value proposition content
- Marketing campaign execution plans
- Additional section proposals
- Content not traceable to source files
