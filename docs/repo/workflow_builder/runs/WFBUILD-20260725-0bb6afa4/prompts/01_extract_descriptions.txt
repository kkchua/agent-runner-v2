Objective

Extract structured image descriptions from input images using LLM vision.

Scan the input image directory for PNG, JPG, and WEBP files. For each image,
produce a structured description JSON file containing 9 attribute groups with
49 total attribute fields. Write an index.json manifest listing all produced
description files.

If the input directory contains no images, return REJECTED with reject_code
NO_INPUT_IMAGES and a descriptive remark indicating no images were found.

Reference Inputs

- Input image directory: {STEP_00_DIR}
- Input archive directory: {STEP_00_ARCHIVE}
- Output directory for descriptions: {STEP_01_DIR}
- Output archive directory: {STEP_01_ARCHIVE}
- Media configuration file: {MEDIA_CONFIG}
- Layer 1 governance documentation: {GOVERNANCE_RUNTIME_ROOT}
- Layer 2 platform documentation: {PLATFORM_RUNTIME_ROOT}

Output Instructions

1. Scan {STEP_00_DIR} for files with extensions .png, .jpg, .jpeg, .webp.

2. If no images are found, return REJECTED with reject_code NO_INPUT_IMAGES.

3. For each image file, analyze the image using LLM vision and produce a
   description JSON file. The filename is derived from the input image stem
   (e.g., image001.png produces image001.json).

4. Each description JSON must contain these top-level fields:
   - image_filename: original input filename
   - image_stem: input filename without extension
   - descriptions: array containing one or more description entries

   Each description entry contains these 9 attribute groups:

   a. subject_attributes (6 fields):
      - main_subject: string identifying the primary subject
      - subject_type: string categorizing the subject type
      - subject_description: detailed string description
      - distinctive_features: list of strings
      - recognizable_objects: list of strings
      - subject_state_or_pose: string describing state or pose

   b. scene_attributes (9 fields):
      - setting: string describing the setting
      - environment: string describing the environment
      - foreground: string describing foreground elements
      - midground: string describing midground elements
      - background: string describing background elements
      - time_of_day: string describing time of day
      - season_or_weather: string describing season or weather
      - spatial_depth: string describing spatial depth
      - parallax_potential: string describing parallax potential

   c. composition_attributes (7 fields):
      - orientation: string describing orientation (landscape/portrait)
      - framing: string describing framing style
      - camera_angle: string describing camera angle
      - subject_position: string describing subject position
      - negative_space: string describing negative space usage
      - visual_flow: string describing visual flow
      - depth_layers: list of strings describing depth layers

   d. lighting_attributes (6 fields):
      - lighting_type: string describing lighting type
      - light_direction: string describing light direction
      - light_quality: string describing light quality
      - color_temperature: string describing color temperature
      - shadow_highlight_behavior: string describing shadow/highlight behavior
      - atmospheric_lighting: string describing atmospheric lighting

   e. style_attributes (5 fields):
      - visual_style: string describing visual style
      - medium: string describing medium
      - realism_level: string describing realism level
      - texture_quality: string describing texture quality
      - rendering_treatment: string describing rendering treatment

   f. color_attributes (4 fields):
      - dominant_colors: list of strings describing dominant colors
      - accent_colors: list of strings describing accent colors
      - color_contrast: string describing color contrast
      - palette_mood: string describing palette mood

   g. mood_attributes (3 fields):
      - emotional_tone: string describing emotional tone
      - atmosphere: string describing atmosphere
      - viewer_feeling: string describing intended viewer feeling

   h. motion_potential (7 fields):
      - primary_motion_candidate: string describing primary motion candidate
      - subject_motion_candidates: list of strings
      - environmental_motion_candidates: list of strings
      - camera_motion_candidates: list of strings
      - motion_intensity_suggestion: string describing motion intensity
      - motion_pacing_suggestion: string describing motion pacing
      - motion_constraints: list of strings describing motion constraints

   i. extraction_confidence (2 fields):
      - overall_confidence: string (high/medium/low) indicating overall confidence
      - uncertain_attributes: list of strings listing uncertain attributes

5. After extracting all descriptions, copy processed input images from
   {STEP_00_DIR} to {STEP_00_ARCHIVE} and remove them from {STEP_00_DIR}.

6. Write an index.json manifest at {IMAGE_DESCRIPTIONS} with this structure:
   - step: "extract_descriptions"
   - files: array of objects, each with "input" (source image path) and
     "output" (produced description JSON path) fields

7. Write a meta.json sidecar reporting status, remark, and artifacts produced.
   Set IMAGE_DESCRIPTIONS to the absolute path of the index.json file.

- All output files must use ASCII characters only.
- All JSON files must be valid UTF-8 JSON.
