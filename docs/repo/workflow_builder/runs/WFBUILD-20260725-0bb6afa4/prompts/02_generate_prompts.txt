Objective

Generate prompt variants from structured image descriptions using LLM text
generation.

Read the structured description JSONs from the descriptions directory. For
each input image, produce a prompt variant JSON file containing N variant
prompt sets (configurable via MEDIA_CONFIG num_variants, default 4). Write
an index.json manifest listing all produced variant files.

Reference Inputs

- Description directory: {STEP_01_DIR}
- Output directory for variants: {STEP_02_DIR}
- Description archive directory: {STEP_01_ARCHIVE}
- Media configuration file: {MEDIA_CONFIG}

Output Instructions

1. Read num_variants from {MEDIA_CONFIG} (default 4 if not specified).

2. Read each description JSON file from {STEP_01_DIR}.

3. For each description JSON, analyze the 9 attribute groups and generate
   a prompt variant JSON file. The filename is derived from the image stem
   (e.g., image001.json produces image001.json in the variants directory,
   or a unique variant filename per image).

4. Each variant JSON must contain these top-level fields:
   - mode: string with value "BASE" (the only mode for v1)
   - subject: string containing the image stem
   - variations: array of N variant objects

   Each variant object must contain:
   - t2i_prompt1: Text prompt in English. This prompt will be used for both
     image generation (text-to-image) and video motion (image-to-video).
     The prompt should be descriptive, detailed, and suitable for AI image
     generation. Consider all 9 attribute groups when crafting the prompt.
   - image_filename: Output image filename in format {stem}_{NN}.png where
     NN is a zero-padded 1-based variant index (01, 02, 03, ...). For
     example, if the image stem is "image001" and there are 4 variants,
     the filenames would be: image001_01.png, image001_02.png,
     image001_03.png, image001_04.png.

5. After generating all variants, copy processed description JSONs from
   {STEP_01_DIR} to {STEP_01_ARCHIVE} and remove them from {STEP_01_DIR}.

6. Write an index.json manifest at {PROMPT_VARIANTS} with this structure:
   - step: "generate_prompts"
   - files: array of objects, each with "input" (source description JSON path)
     and "output" (produced variant JSON path) fields

7. Write a meta.json sidecar reporting status, remark, and artifacts produced.
   Set PROMPT_VARIANTS to the absolute path of the index.json file.

- All prompts must be in English.
- All output files must use ASCII characters only.
- All JSON files must be valid UTF-8 JSON.
