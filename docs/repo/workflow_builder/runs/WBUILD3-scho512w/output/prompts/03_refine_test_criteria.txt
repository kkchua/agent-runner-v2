# Objective

Fix issues identified in the review of the acceptance criteria document.
This is a refinement step that addresses specific feedback from the
reviewer while preserving the overall structure.

This step rewrites the TEST_CRITERIA_FILE.

## Reference Inputs

Read the following files before producing any output:

- REVIEW_TEST_CRITERIA_FILE: {REVIEW_TEST_CRITERIA_FILE}
  Read the review verdict. Identify all issues flagged as requiring
  fixes. Pay attention to the specific sections and criteria called out.

- TEST_CRITERIA_FILE: {TEST_CRITERIA_FILE}
  Read the current test criteria document. This is the base to modify.

## Refinement Rules

1. **Root cause fixes** -- Fix the underlying issue, not just the
   symptom. If a criterion is vague, rewrite it with specific,
   verifiable language.

2. **No scope addition** -- Do NOT add new sections, new criteria
   beyond what the review requires, or new spec sections not
   previously covered.

3. **Preserve approved content** -- Do NOT modify sections that
   passed review. Only modify sections identified in the review.

4. **Maintain traceability** -- Every modified criterion must still
   trace to a spec section.

5. **Fix all issues** -- Address every issue listed in the review
   verdict. Missing an issue will cause another rejection.

## Self-Critic

Verify your fixes:
- Did you fix root causes, not symptoms?
- Did you address every issue from the review?
- Did you avoid adding new scope?
- Did you preserve sections that already passed review?

## Forbidden Content

- Do NOT ask clarifying questions.
- Do NOT add scope beyond what the review requires.
- Do NOT modify sections that passed review.
- Do NOT include non-ASCII characters.

## Output Instructions

Use file-writing tools to write the refined test criteria to:
{TEST_CRITERIA_FILE}

Format: Markdown with YAML frontmatter (same as original).
Update the total_criteria_count if criteria were added or removed.

ASCII-only content.

The result field in meta.json is for status summary ONLY. Write all
content to the file specified above.
