# Objective

Generate comprehensive acceptance criteria for the Workflow Builder v3
meta-meta builder. These criteria define what makes the generated
artifacts correct, complete, and verifiable.

This step produces the TEST_CRITERIA_FILE.

## Reference Inputs

Read the following files before producing any output:

- WORKFLOW_SPEC_FILE: {WORKFLOW_SPEC_FILE}
  Read the entire specification. Pay attention to:
  - Section 2: Component Schema requirements (8 component types)
  - Section 3: Composition Format requirements (8 binding rules, 6 patterns)
  - Section 4: Output Format requirements (3-part output, resolution rules)
  - Section 5: Operational Workflow requirements (9 phases, step sequence)
  - Section 5.1: Phase definitions
  - Section 5.5: Package file inventory

## Generation Tasks

Produce a test criteria document with the following sections:

1. **Introduction** -- Scope and purpose of the acceptance criteria.
   State that these criteria apply to the Workflow Builder v3 workflow.

2. **Criteria for Foundation Phase (Phase 1)** -- Acceptance criteria
   for generate_test_criteria, review_test_criteria, and
   refine_test_criteria. Each criterion must be specific and verifiable.

3. **Criteria for Component Schema (Phase 2)** -- Criteria verifying
   that the component schema defines all 8 component types, common
   properties, type-specific properties, validation rules (VR-001
   through VR-014), and examples.

4. **Criteria for Composition Format (Phase 3)** -- Criteria verifying
   that the composition format defines 8 binding rules, 6 workflow
   patterns, override mechanism, placeholder resolution, and ordering
   rules.

5. **Criteria for Output Format (Phase 4)** -- Criteria verifying
   that the output format defines the 3-part output structure, 7
   resolution rules, and quality requirements.

6. **Criteria for Operational Workflow (Phase 5)** -- Criteria verifying
   all 9 phases, 21 steps, step types, routing, artifact flow integrity.

7. **Criteria for Composition Standard (Phase 6)** -- Criteria verifying
   the v3 innovation: composition standard with standard_name,
   standard_version, component_types_defined, schema_sections,
   extensibility_model.

8. **Criteria for Meta Composition Spec (Phase 7)** -- Criteria verifying
   the v3 innovation: meta spec with 5 sections, self-bootstrapping
   capability.

9. **Criteria for Package Assembly (Phase 8)** -- Criteria verifying
   all package files (workflow.toml, context_extensions.py, actions.py,
   prompts/, README.md), deterministic validation, gatekeep, review.

10. **Criteria for Promotion (Phase 9)** -- Criteria verifying package
    deployment and step completion.

11. **Negative Criteria** -- Things that MUST NOT appear in any output
    (non-ASCII, dangling references, scope invention).

12. **Self-Validation** -- Verification that the criteria document
    covers all spec sections and all criteria are verifiable.

## Self-Critic

Challenge your reasoning before checking completeness:
- Did you cover all 9 phases from the spec?
- Is every criterion specific enough to be verified by a gatekeeper?
- Are there any vague criteria like "must be correct" that cannot be
  objectively tested?
- Did you include criteria for the v3 innovations (composition standard
  and meta composition spec)?

## Forbidden Content

- Do NOT include vague criteria like "must work properly" or "must be
  correct."
- Do NOT include criteria that reference sections not present in the spec.
- Do NOT include non-ASCII characters.
- Do NOT ask clarifying questions.
- Do NOT invent requirements beyond what the spec defines.

## Output Instructions

Use file-writing tools to write the complete test criteria document to:
{TEST_CRITERIA_FILE}

Format: Markdown with YAML frontmatter
Frontmatter must include:
  doc_type: "test_criteria"
  lifecycle_status: "draft"
  domain: "workflow_builder"
  total_criteria_count: (the actual count)

ASCII-only content. No em-dashes, no curly quotes.

The result field in meta.json is for status summary ONLY. Write all
content to the file specified above.
