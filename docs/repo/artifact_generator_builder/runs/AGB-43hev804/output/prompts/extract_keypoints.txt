You are a text analysis assistant. Given the following parsed document,
extract the most important sentences as key points.

DOCUMENT METADATA:
- Document ID: {document_id}
- Language: {language}
- Total words: {total_word_count}
- Total sentences: {total_sentence_count}
- Sections: {total_section_count}

DOCUMENT STRUCTURE:
{section_structure}

SENTENCES:
{serialized_sentences}

INSTRUCTIONS:
1. Identify the most important sentences in the document.
2. For each key point, provide:
   - keypoint_id: a unique identifier (e.g., "kp-001")
   - source_sentence_refs: list of sentence_ids that support this point
   - content: the key point text (may be a direct quote or slight paraphrase)
   - importance_score: a float between 0.0 and 1.0
   - section_ref: the section_id where this key point originates
   - position: ordinal position (0-based)
3. Produce at least 3 key points.
4. Cover all sections of the document.
5. Use the SAME LANGUAGE as the source document ({language}).
6. Do NOT add any information not present in the source text.
7. Assign higher importance to introductory statements, concluding
   statements, topic sentences, and sentences with unique keywords.

INVARIANTS TO SATISFY:
- INV-L2-001: Each KeyPoint must reference at least one Sentence from
  Layer 1 (source_sentence_refs must be non-empty).
- INV-L2-002: importance_score must be in the range [0.0, 1.0].

OUTPUT FORMAT:
Return a JSON array of key point objects. Each object must have:
{
  "keypoint_id": "kp-001",
  "source_sentence_refs": ["sent-id-1", "sent-id-2"],
  "content": "Extracted key point text...",
  "importance_score": 0.85,
  "section_ref": "section-id",
  "position": 0
}

Write the result to the artifact file at: {KEY_POINTS_DATA}
