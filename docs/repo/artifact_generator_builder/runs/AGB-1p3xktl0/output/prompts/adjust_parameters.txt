# Adjust Parameters: Text Summarizer Pipeline

## Step Identity

- **Step name:** adjust_parameters
- **Workflow:** text_summarizer_ayz
- **Role policy:** architect_standard
- **Phase:** Auxiliary (Refinement Only)
- **Activation:** Only during quality review refinement

## Your Task

The quality review step has determined that the generated outputs do
not meet quality standards. Based on the review feedback, you must
adjust the pipeline configuration parameters to improve output quality.

After adjustment, the pipeline will re-execute from parse_input
(Step 3) with the updated parameters.

## Inputs

- **QUALITY_REVIEW_REPORT:** {QUALITY_REVIEW_REPORT}
  The quality review report containing specific feedback about which
  quality dimensions failed and recommended adjustments.

- **CONFIG_STATE:** {CONFIG_STATE}
  The current pipeline configuration with all parameter values.

- **STEP_SEQUENCE_FILE:** {STEP_SEQUENCE_FILE}
  The step sequence defining the pipeline structure.

- **ARTIFACT_CONTRACT_FILE:** {ARTIFACT_CONTRACT_FILE}
  The artifact contract defining all artifacts and constraints.

## Current Configuration Parameters

The following parameters can be adjusted:

| Parameter | Current Value | Range | Effect |
|---|---|---|---|
| compression_ratio | from CONFIG_STATE | (0.0, 1.0] | Maximum summary/source word count ratio |
| keypoint_threshold | from CONFIG_STATE | [0.0, 1.0] | Minimum importance score for key point extraction |
| similarity_threshold | from CONFIG_STATE | [0.0, 1.0] | Jaccard similarity threshold for redundancy clustering |
| output_format | from CONFIG_STATE | md, txt, json | Output serialization format |
| scoring_method | from CONFIG_STATE | positional_tfidf | Importance scoring algorithm |
| clustering_method | from CONFIG_STATE | keyword_overlap | Redundancy detection algorithm |

## Adjustment Guidelines

Based on the quality review feedback:

### If Core Message Capture Failed
- Decrease keypoint_threshold to include more content
- Consider increasing compression_ratio if summary is too short

### If Logical Coherence Failed
- Adjust similarity_threshold to change how aggressively
  redundancy is removed
- Consider modifying the summary composition strategy

### If Information Preservation Failed
- Increase compression_ratio to allow more content
- Decrease keypoint_threshold to extract more key points

### If Key Point Quality Failed
- Increase keypoint_threshold to extract fewer but higher-quality points
- Adjust similarity_threshold to change redundancy grouping

### If Readability Failed
- Adjust similarity_threshold to change how sentences are combined
- Consider modifying compression_ratio

## Output Requirements

Write the adjusted configuration to: {ADJUSTED_CONFIG}

The output MUST be a valid JSON object containing:

1. All current configuration parameters (carry forward unchanged values)
2. Modified values for parameters you are adjusting
3. A "adjustment_reason" field explaining why each parameter was changed
4. A "review_iteration" field indicating which refinement cycle this is

## Constraints

- Do NOT change parameters that are not related to the quality issues.
- Make targeted adjustments based on specific review feedback.
- Ensure all parameter values remain within valid ranges.
- The adjusted configuration must still satisfy all global invariants
  (GI-001 through GI-006).
- ASCII-only output. No em-dashes, curly quotes, or Unicode.

## Recovery Loop Information

- Maximum iterations: 2
- If this is iteration 2 and quality still fails, the workflow will
  halt with QUALITY_REVIEW_EXHAUSTED and require human intervention.
