# Codebase Documentation Status Rules

## Purpose

This document defines the status lifecycle for codebase documentation within
the repository.

## Status Values

Codebase documentation uses the following lifecycle statuses:

| Status | Meaning |
|--------|---------|
| `draft` | Initial version, under review |
| `approved` | Active documentation, reflects current state |
| `superseded` | Replaced by newer version |
| `deprecated` | No longer maintained, kept for reference |

## Status Transitions

```
draft -> approved (after review)
approved -> superseded (when replaced)
approved -> deprecated (when no longer relevant)
```

## Approval Process

Codebase documentation generated by `ukbe-run-agent codebase-init` or
`sdlc_00_codebase_v1` is automatically set to `approved` status, as it
reflects the current state of the repository.

## Validation Rules

All codebase documentation must:

1. Have valid YAML frontmatter
2. Include required metadata fields
3. Use ASCII-only content
4. Follow the documentation structure defined in CODEBASE_DOC_SOP.md
