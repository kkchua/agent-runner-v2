# Prompt Layout

Use this logical order for prompts in this bundle:

1. Objective
2. Layer Boundary
3. Required Inputs
4. Output Responsibilities
5. Required Content
6. Forbidden Content
7. Decision Rules
8. Output Instructions

Recommended headings:

- `Objective`
- `Layer Boundary`
- `Reference Inputs`
- `Artifacts`
- `Required Content`
- `Forbidden Content`
- `Review Decision` or `Audit Decision`
- `Output Instructions`
