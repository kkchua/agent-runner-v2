# STEP 02 - Generate Image & Video Prompts (Enhanced Reconstruction) v7

---

# Mission

Your mission is to convert every individual image description JSON generated in STEP 01 into a high-quality Image Prompt JSON and Video Prompt.
This step is a reconstruction task, NOT a summarization task.
The objective is to regenerate an image that is visually indistinguishable from the original source image while producing multiple high-quality photographic interpretations.

---

The STEP 01 output directory contains:

Never generate prompts directly from index.json.

# Reconstruction Objective

Do NOT summarize the description JSON.
Treat the JSON as semantic evidence describing an existing photograph.
Your objective is to reconstruct the original image as faithfully as possible.
The generated prompt should maximize reconstruction fidelity instead of creativity.
When information is missing, infer only realistic photographic properties.
Never invent new semantic content.

# Visual Style Rules (MANDATORY — PHOTOREALISTIC ONLY)

CRITICAL: ALL image prompts (t2i_prompt1) MUST produce photorealistic,
photographic-quality images. The generated images are used as Frame 1 for
video generation (image-to-video). Non-photographic rendering styles
produce poor video results: flickering, morphing, texture instability, and
temporal inconsistency during motion.

Every variant MUST use a real-camera photographic style. Visual variety
between variants must come from different photographic techniques
(lighting, lens, framing, color grading) — never from switching art medium.

## Strictly Forbidden Styles (Will Break Video Rendering)

- Oil painting / impasto / brushstroke textures
- Watercolor / ink wash
- Digital painting / concept art / matte painting
- Anime / cartoon / cel-shaded
- Illustration / pen and ink / graphic art
- Sketch / charcoal / pencil
- 3D render / CGI look
- Pixel art / voxel
- Pointillism / stipple
- Any non-photographic art medium

## How to Add "painterly" or "artistic" Quality Without Breaking Photorealism

If the source image description suggests an artistic or stylized feel,
achieve it through PHOTOGRAPHIC means only:
- Soft bokeh and shallow depth of field (not brushstrokes)
- Golden hour or blue hour lighting (not painted skies)
- Film grain and analog color tones (not watercolor washes)
- Lens flare and optical effects (not digital painting overlays)
- Selective focus and tilt-shift (not illustration techniques)

This applies to every variant without exception.

# Variant Generation

Generate exactly 5 variants.

Variant 1

Faithful reconstruction

Closest possible recreation of the original photograph.

Variant 2

Cinematic interpretation

More dramatic framing, cinematic lighting, stronger visual storytelling.

Variant 3

Fine Art interpretation

Elegant composition, artistic atmosphere, premium gallery photography style
(achieved through photographic technique only — see Visual Style Rules).

Variant 4

Epic Landscape / Environmental interpretation

Large sense of scale, environmental storytelling, immersive composition.

Variant 5

Professional Editorial interpretation

Magazine-quality composition, premium color grading, polished commercial photography.

---

# Variant Diversity Rules

Every variant must preserve semantic fidelity.

However each variant should maximize photographic diversity.

Across all five variants intentionally vary combinations of:

- camera position
- camera height
- camera distance
- framing
- perspective
- focal length
- aperture
- depth of field
- lighting direction
- lighting intensity
- atmosphere
- weather intensity (only if consistent with original)
- color grading
- photographic style

Do NOT create variants by changing only one parameter.

Each variant should look like it was photographed by a different professional photographer.

Every variant should feel visually distinct while still clearly depicting the same original scene.

Do not reuse the same sentence structure between variants.

Rewrite each prompt independently.
