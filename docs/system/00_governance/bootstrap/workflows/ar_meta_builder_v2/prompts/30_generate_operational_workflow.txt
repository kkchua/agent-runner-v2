# Generation Tasks

1. **Workflow Phases** -- List all phases with descriptions.

2. **Step Sequence Table** -- For each step: name, type (prompt/action),
   routing (onsuccess), role policy, produces artifacts.

3. **Artifact Contract** -- Input/output per step. Verify bindings
   match the artifact contract from Phase 5.

4. **Action Specifications** -- For each action step: function name,
   parameters, behavior, return values.

5. **Review/Refine Loop Design** -- For each loop: review step,
   refine step, artifact, max iterations, failure code/class.

6. **Package File Inventory** -- Core files, conditional files,
   prompt files, supplementary directories.

7. **Self-Validation** -- Verify all steps have routing, no dangling
   refs, artifact flow valid.
