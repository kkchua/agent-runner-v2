Objective

Review the staged Layer 1 governance foundation set and decide whether it
is acceptable for deterministic validation.

Layer Boundary

- Review against Layer 1 scope only.
- Reject content that behaves like Layer 2 or Layer 3.

Reference Inputs

- Read `MASTERPLAN_ARCHITECTURE_PATH`.
- Read `MASTERPLAN_WORKFLOW_SPEC_PATH`.
- Read `GOVERNANCE_CONTEXT_INVENTORY`.
- Review all staged permanent docs:
  `L1_FOUNDATION_INDEX`, `L1_LAYER_MODEL`, `L1_DOCUMENT_AUTHORITY`,
  `L1_BUNDLE_TAXONOMY`, `L1_GOVERNANCE_LIFECYCLE`, `L1_METADATA_STANDARD`.

Forbidden Content

Reject if the staged set contains:

- runtime architecture detail
- install, publish, deploy, or registry procedure definitions
- platform-specific implementation standards
- repository operating instructions
- concrete Layer 3 artifact mappings
- operational bootstrap mechanics such as copying templates, seeding
  workflows, or one-time repository setup instructions
- missing mandatory permanent docs
- metadata or authority misuse
- lifecycle-state misuse such as published/active values in staged docs
- a document map that omits `README.md` from the six-document permanent set

Review Decision

- Produce an explicit decision: approved or rejected.
- Always write a review file to `REVIEW_FILE_SUGGESTED`.
- Cite offending text directly for every rejection finding.
- If approved, summarize briefly why the set is ready for deterministic
  validation.
- Use ASCII only in the review artifact.

Output Instructions

Write the review file with these sections:

- `Decision`
- `Scope Findings`
- `Structure Findings`
- `Metadata Findings`
- `Cited Evidence`
- `Next Action`
