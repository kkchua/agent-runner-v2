# Prompt SOP

1. Every prompt must state that the workflow belongs to Layer 1.
2. Every prompt must distinguish permanent governance artifacts from temporary evidence artifacts.
3. Generate prompts must treat `masterplan/LAYER_ARCHITECTURE_MASTERPLAN.md` and `masterplan/LAYER1_GOVERNANCE_SPECIFICATION.md` as read-only authority inputs.
4. Review and audit prompts must require direct citations to offending text when rejecting content.
5. Refine prompts must prefer removal, reclassification, or rejection over polishing wrong-scope content.
6. No prompt may instruct the model to define runtime internals, install procedures, publish procedures, registry operations, or platform-specific contracts as Layer 1 content.
7. Prompt edits that change scope or output contracts must be reviewed against the bundle governance package before acceptance.
